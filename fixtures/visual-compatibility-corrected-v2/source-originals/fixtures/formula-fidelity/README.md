# 明确选取的公式保真作者样例

本目录为可公开的自造工程材料，按 CC0 使用；不含用户资料、生产 Vault、真实模型调用或科学正确率基准。公式只用于检验源码字节、符号、下标、指数、负号、分式、关系符号及必要上下文的保留。

每个输入目录只由 `case.json` 明确选择原始 TeX、符号定义与前提的 `semantics.json`、已经选定的 `region.png`。PNG 是已选公式区域原件，区域在虚构页画布中的定位由 page/canvas/bounds 明确给出；程序不裁图、不扫描目录、不做 OCR。图片由独立作者以数学排版手工绘制；`formula_region` 的 expression 是作者明确手工语义转写，不是恢复的作者 TeX。

`expected-*.json` 保存独立作者确定的原件指纹、完整上下文、结构 token 与决策预期。普通 CLI 不读取 expected。`frozen-sha256.json` 在旧 CLI 的真实 RED 前冻结；独立校验器固定其 SHA，不可把当前输出自动接纳为新预期。

覆盖源码 CRLF 原件、负号与上下标、关系符号、指数函数、dfrac 兼容另存、能力不足原图、仅原区、未确认符号、不可辨原区、未知宏、源码/语义声明不一致及无原始数据曲线。曲线只是防止虚假重绘的保护输入，完整图像重现仍需后续验收。

profile-native 声明已测 Obsidian 1.6.7 / MathJax 3.2.2 能力，其他 profile 有意关闭能力或标记未核验。声明本身不是实机验收证据，最终 CLI 输出必须在相同版本干净 Obsidian 中实际核对。
