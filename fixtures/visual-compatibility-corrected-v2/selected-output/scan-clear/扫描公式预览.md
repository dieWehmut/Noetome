## 公式

$$
x_i=-\frac{a_i}{b_i}
$$

该表达由选定扫描区域重建，并经符号与前提核对；作者原始 TeX 未知。

## 识别原表达

```text
x_i = -\frac{a_i}{b_i}
```


```text

```

单位：

```text
dimensionless
```

## 适用前提

```text
a_i >= 0.
```

```text
b_i > 0.
```

## 范围

```text
i in {1, 2}.
```

```text
x_i <= 0.
```

## 例外

```text
If b_i = 0, the expression is undefined.
```
