# 无图文字主动表达作者样例

这些是公开自造的离线工程材料（fake），不是教材、真实模型输出或科学金标准。科学状态 not_run、知识 pending、published=false。数值只检验明确身份的结构保留与主动表达选择。

`authors.json` 在任何候选构造或 CLI 调用前声明每份旧 Gold2、动态 subject/property、严格 Schema3 identity/context 和独立 coordination_expected。`.txt` 原文只有 source_context_zh_v1 背景与文字事实，没有表格、成图或 NotePlan。每份输入由普通 source import / extract verify 获得真实来源链，只有实际成功的 coordinate IR 可进入 present；不直接构造 passed 的依据。

每份 `expected-*.json` 预先声明表示选择及对象/属性/单元格语义：值、原单位、完整条件、例外、适用状态、时间与全部原出现。它不指定实现的 node_id、行列编号、Markdown字节或最终布局。缺失仅指选定事实未给出，不推定整个来源没有该知识；不适用条件仍可有已知数值。表格条件/历史单元格须保留全部事实组，重复事实保留每份来源支持。

案例覆盖两对象共同属性、三事实一缺失、单对象正文、无共同属性正文、known/NA、多条件单元格、同一来源的真实不同版本与历史单元格、中文/单括号/竖线/数学明文、不同原单位并列、未决冲突及未知条件阻断。`history_cell` 的三次导入使用同一显式 source_id；其他案例各使用独立 source_id。对象标签也来自原文动态 subject，不能把两份“样例 A”只凭显示改名成两个对象。

`frozen-sha256.json` 签名本目录全部其他作者文件原字节。正式驱动先读回签名并将作者源、Gold2与预期保存到新的测试根，然后才调用 CLI。候选仅 local_http_test 工程构造，所有原子仍 unverified/required=false。运行后禁止从协调或呈现产物回填预期。旧 B02/B05 作者与原件保持原样。

这些样例不证明任意文字的理解、单位换算、科学正确率、全部 PDF 支持、生产 Vault 维护或 Obsidian 兼容性。真实渲染与路径/并发保护需由本任务另行实测。
