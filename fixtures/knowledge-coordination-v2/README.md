# 调用前作者条件与时间样例

这是公开自造的 `source_context_zh_v1` 工程材料，producer=fake、科学 not_run、知识 pending、published=false。数值和观点时间只用于结构与出处验收，不来自真实科学资料、模型或教材。它们不能证明一般科学演变、单位换算或真实准确率。

`authors.json` 保存每个案例的完整旧 Gold2、显式 v2 identity 与已独立声明的 expected；各 `.txt` 是对应实际源字节。先冻结这些作者文件并保存 SHA，再构造候选、运行 source import/extract verify/knowledge coordinate。expected 的每组值、单位、全部条件/例外、条件状态、时间、原 ID、pair 关系与实际分母在调用前存在；运行后禁止从协调报告回填。

案例包括 20/30 ℃及成年样例范围、例外、两种年份、有效闰日、未知条件、明确不适用、两者并列、不同单位、未给出时间、year/day 重叠、条件和时间同时不同。same_source 的有/无时间案例通过明确导入同一已登记 source_id 的两个版本保留历史出处，独立来源预期为1；普通多源为2或3。实际时间来自紧邻 gold.quote 的背景整行与原 supports，不能使用文件名、mtime或响应时间。

旧 `knowledge-coordination-v1`、B04 gold/IR 和原真实调用原件保持原样。实现/普通行为证据与未完成范围见 [B05-T02验收](../../doc/validation/B05-T02.md)。
