# 明确选定图像作者样例

本目录是可公开自造的 CC0 工程素材。原 PNG 由独立作者使用 Pillow 以手工像素坐标绘制，结构声明也是作者手工转写；不代表自动图像理解、OCR、科学正确率或实际实验数据。图像全部是明确选定整图，dimensions 是实际 PNG 画布，不是假造 PDF 页码或定位区域。

普通 CLI 只接收一个 case 目录和 profile，不读取本目录 expected。expected 保存调用前原件字节指纹、作者完整标签、单位、箭头方向/正负、图例归属、几何和空间关系以及独立决定。frozen-sha256.json 在旧 CLI 的真实 RED 之前冻结；checker 固定其 SHA，不能从产品 SVG 或计划反推预期。

12 场景覆盖正负箭头、包含/左右/上下空间、XML 特殊文字、已知但不支持的几何回退、无数据曲线原图保留、未知标签/关系/空间阻断、不可辨原图阻断、未验证目标/无 SVG 原图回退和缺本地图像能力阻断。原件同时保存不代表未知语义被确认。原图保留和有限 SVG 只是工程表达核对，知识始终 pending、科学质量 not_run、published=false。
