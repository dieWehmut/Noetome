# Cross-Role Presentation Author Fixture

This public, self-authored engineering case is frozen before candidate or CLI calls. Synthetic measurements and labels test structural behavior; scientific quality remains `not_run`, knowledge remains `pending`, and publication remains false.

`cross_role_disjoint_paragraph` explicitly assigns concept X (`速度`) as input `a`'s object and input `b`'s property. Input `a` has property Y (`密度`), and input `b` has object Z (`样例 B`). Each atom has different object and property identities, so the existing strict coordination contract permits the mapping. The two objects have no shared property and therefore require paragraph presentation. A concept's legal reuse across atoms must not be rejected by combining object-label and property-label uniqueness checks.

The two plain sources contain source-backed applicability and year-precision time. `authors.json` freezes Gold2, schema-3 identity, and independent coordination facts, occurrences, relations and counts. `expected-*.json` independently fixes raw values, units, full conditions and exceptions, context, labels, source references and paragraph semantics; it supplies no NotePlan, output layout or generated IDs.

`frozen-sha256.json` signs every other file. The original 11-case and legacy author packages remain unchanged.
