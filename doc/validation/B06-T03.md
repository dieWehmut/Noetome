本项按 [B06 执行卡](../execution/B06_STEPS.md)和[公式契约](../technical/FORMULA_FIDELITY_CONTRACT.md)实现。最终完成状态由任务账本维护；下面只登记实际执行及其证据，不由文件存在推定完成。

## 实现与边界

普通入口为 `noetome knowledge formula <case目录> <profile.json> <新测试Vault>`。选定来源使用独立附件命名空间，严格持有 manifest、原始 TeX、作者语义声明、已经选取的 PNG 和 profile。CLI 不读取独立 expected；不扫描其他资料、不调用模型、不执行 OCR，也不向生产 Vault 或项目数据库写入。

有界 grammar 支持标量表达、数字、括号、正负与乘除、关系链、上下标，以及 `\frac`、`\dfrac`、`\exp`、`\alpha`、`\beta`、`\gamma`、`\le`、`\ge`。逐 token 核对原始 TeX 与作者明确手工转写，全部变量需要定义；单位、前提、范围、例外完整保留。只忽略 ASCII 数学空白并核对分式规范化，不执行代数推断。

原始 TeX / PNG / 语义声明保留逐字节相同和 SHA。原生编译输入另存，兼容决策依据原始源码中的命令，不依据转写的不同拼写。语义可核对时可以回退原区域；未知符号、未知宏、表达不符、不可辨原区和无数据曲线保留原件及失败双报告，没有成功计划或笔记。PNG 完整解码、CRC、IEND、区域定位和尺寸验证，拒绝 APNG、尾随载荷、损坏和越界；文件上限 8 MiB、区域 2048×2048、解码内存 32 MiB。

所有成功均为知识 pending、科学质量 not_run、published=false 的工程预览。手工转写不是恢复作者 TeX；自造样例不证明真实文献科学正确率、任意宏、积分/矩阵/化学式、扫描重建、一般图像知识重绘或发布兼容矩阵。
