# 长时运行 soak（soak-synthetic-v1）

这一份是**合成**的长时运行观察：工作单元是对一页合成文本做只读分析，不含任何教材内容，也不代表真实项目负载。

## 参数

- 轮次：10
- 轮间隔：0 毫秒
- 暂停时点：0 毫秒
- 内存增长上限：1073741824 字节

## 工作单元

每轮的工作单元是对一页合成文本跑一次只读分析并核对摘要；不写文件、不联网、不调用模型。

## 暂停闸门

- 时限：暂停后 2000 毫秒内必须停止调度新请求（NFR-13）。
- 判定口径：每一轮开始时记下距起点的毫秒数；暂停时点之后的所有轮次都必须是 refused。
- 可观测计数：闸门关闭后仍被调度的轮数必须为 0，读数在 `timings.json` 的 `pause.scheduled_after_pause`。

## 覆盖范围与未达标项

- **NFR-09**：not_met——NFR-09 要求连续 24 小时（86400000 毫秒）基准运行。本 harness 按轮次运行，本轮计划时长下限只有 0 毫秒；实际跑了多久写在 timings.json，未跑满 24 小时即未达到 NFR-09，不把短时结果当长时结论。
- **NFR-13**：partially_measured——闸门关闭后不再调度新单元这件事由可观测计数证明：每轮开始时记下距起点的毫秒数，暂停时点之后的所有轮次都必须是 refused。真正的「应用暂停命令」还没有界面，所以这里只标 partially_measured，时限常量是 2000 毫秒。

## 边界

- 读数写在 `timings.json`：本文件不含本次运行的任何耗时或内存读数，写进来同一参数两次运行就不再相同；上面出现的毫秒数只有规则常量。
- 合成负载：工作单元只跑文本分析，不写项目、不写 Vault、不联网、不调用模型。
- 复现命令：`noetome soak run --rounds 10 --interval-ms 0 --pause-after-ms 0 --max-rss-growth-bytes 1073741824 --output <输出根>`
