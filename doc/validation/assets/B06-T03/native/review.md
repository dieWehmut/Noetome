# B06-T03 Rust 与契约独立审查

审查者负责本任务实际 Obsidian 验收，没有编写被审查的 Rust 产品模块。逐路径审阅当前 `formula.rs`、`formula_input.rs`、`formula_model.rs`、`formula_parser.rs`、`formula_render.rs`、CLI dispatch、`extraction_output.rs` 的新增 owner/cleanup，以及公式契约和作者预期。

## 结论

当前有界实现未发现需要阻断交付的产品缺陷。本结论针对明确选定公式附件的保真编译、回退与阻断，不把 token 一致、作者注释或原生渲染成功解释为科学正确性。完整 Rust/Python 回归和全部独立篡改矩阵仍由相应实际记录证明，代码审查不代替这些检查。

## 核对内容

1. **来源与 schema**：case、semantics 和 profile 拒绝未知字段、省略 nullable 字段和重复键；只接受精确附件清单与明确的普通直接子文件。SHA 与实际字节绑定，source_kind 和所选 TeX/region 的组合不允许混淆。没有项目来源身份冒用，也没有遍历未选私有目录。
2. **数学保真**：语法有明确操作数、分式参数、脚标、括号和关系结构，未知命令、缺少符号定义或原始 TeX 与来源注释不一致均阻断。大小写、负号、脚标内容、分式参数与关系方向进入保真的 token 链；不进行代数猜测或单位换算。单位、前提、范围和例外按原字段进入正文。
3. **兼容行为**：原始 TeX 独立保留，compiled.tex 另存；受控 dfrac→frac 重写之后再次解析核对，改写原因可见于决策。重写取决于原始 TeX 是否使用 dfrac，不因为来源注释的 token 规范化漏记来源改写。关闭该编译器策略时可回退，但实际 MathJax 支持 dfrac 的事实没有被错误否定。
4. **PNG**：坐标、页号、画布、区域大小和 PNG 实际宽高一致；检查完整 chunk framing、IEND 文件终点、APNG 禁止、CRC 和实际解码，具有限定输入、尺寸及解码内存。原件已经是明确选区，不会暗中裁剪或处理一般图像。
5. **回退与阻断**：仅目标表达能力不足可使用语义已明确、可辨的原图；未知符号、未知关键表达、原图不可辨和无数据曲线不能因为文件保存成功而获得成功 plan/笔记。科学质量、知识、发布及网络/付费状态保持独立且如实记录。
6. **输出和保护**：新根必须尚不存在，父目录及来源/profile/输出路径重叠检查先于创建。来源和 profile 在运行中持有并收尾重验，OutputRoot 沿用普通文件、祖先/目录身份、精确清单和硬链接保护。失败清理先移除仍未变化的报告/计划/编译表达/笔记，保留原件和未知现场；有限阶段测试不能外推为所有恶意并发交错都已实测。
7. **渲染与追溯**：固定语法只放入已通过受控语法的 TeX 或选定 PNG；其余来源声明采用可容纳原始反引号的明文 fenced block，防止标题或注释被解释为活跃语法。逐块 UTF-8 范围与来源字段保留；独立核对器及实际 DOM 字段归组检查共同核对符号/定义/单位的所属位置。

审查中一个关于 no-images profile 的疑点已排除：该冻结 profile 的 native_math 实际为 false，因此期望 IMAGE_UNAVAILABLE 与当前实现一致；没有为适配实现改写该预期。

## 真实渲染证据

10 个实际 CLI 产物场景已经在干净 Obsidian 1.6.7 验证，其中 4 个原生 MathJax 3.2.2 公式、3 个原图回退和 3 个阻断报告。4 棵数学树、44 个可见 glyph、33 组具备标签归属的符号声明及完整上下文通过；7 次附件鼠标点击进入正确原生图片视图，原件指纹及复制品不变。最终独立核对器又检查了相同的 10 份源 Vault，全部通过。详细证据见 [原生总结](summary.json)、[字段归组](native-label-association.json)和[最终联结](final-checker/final-checker-linkage.json)。

实际运行时 version=3.2.2 与安装包辅助模块的 3.2.1 字符串不同，首次错误版本断言和修正后的实测都保留。其余采集器的虚拟化、组合脚标、隐式函数应用标记及 glyph 行盒问题也保留为失败原件，没有通过修改产品数学语义规避验收。
