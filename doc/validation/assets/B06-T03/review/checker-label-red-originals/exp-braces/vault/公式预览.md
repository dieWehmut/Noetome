# 公式预览

## 标题

```text
公式保真样例 native_exp
```

## 公式

$$
C_i(t)=C_0\exp{-k t}
$$

## 符号定义

### 符号 1

符号：

```text
C
```

定义：

```text
test concentration
```

单位：

```text
mmol/L
```

### 符号 2

符号：

```text
i
```

定义：

```text
selected integer sample index
```

单位：

```text
来源未给出单位
```

### 符号 3

符号：

```text
t
```

定义：

```text
elapsed time
```

单位：

```text
s
```

### 符号 4

符号：

```text
k
```

定义：

```text
positive decay coefficient
```

单位：

```text
1/s
```

## 适用前提

```text
k > 0
```

## 范围

```text
i = 1,2,3
```

```text
0 <= t <= 10 s
```

## 例外

```text
Do not apply outside the selected time interval.
```
