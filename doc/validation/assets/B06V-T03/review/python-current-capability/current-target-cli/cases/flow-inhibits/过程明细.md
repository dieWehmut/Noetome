# 过程明细

## 过程说明

过程名称：演示鸣响抑制规则

## 步骤-s1

```text
步骤：s1
类型：步骤
名称：启用演示静音控制
说明：把演示静音控制设为启用
判据：不适用（普通步骤）
输入：
1. 静音命令
输出：
1. 已启用静音控制
条件：
1. 演示模式开启
例外：
1. 控制器断开时不生效
```

## 步骤-s2

```text
步骤：s2
类型：步骤
名称：蜂鸣器鸣响响应
说明：表示可能受到抑制的鸣响响应，不断言响应已发生
判据：不适用（普通步骤）
输入：
1. 鸣响请求
输出：
1. 可能的鸣响响应
条件：
1. 蜂鸣器可用
例外：
1. 蜂鸣器断开时不可观察
```

## 关系-r1

```text
关系：r1
起点：s1
起点名称：启用演示静音控制
终点：s2
终点名称：蜂鸣器鸣响响应
含义：−：抑制
条件：
1. 演示静音通道接通
例外：
1. 旁路开启时该抑制不成立
```
