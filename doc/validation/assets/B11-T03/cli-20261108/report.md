## 边界

- 只核对结构与位置：链接是否唯一解析、每个概念是否恰有一处完整解释，不判断内容质量与科学正确性。
- 「完整解释」只认正文里显式写出的 `> 完整解释：<概念>` 标记；没有标记的段落不算声明，标记了也不会自动变成长度合格的讲解。
- 链接只在笔记与标题都唯一时才算可用；同名标题与同名笔记一律记为歧义，不取第一个匹配。
- 表格单元里的别名必须写成 `\|`，未转义即整包拒绝：那是声明错误，不是审计结论。
