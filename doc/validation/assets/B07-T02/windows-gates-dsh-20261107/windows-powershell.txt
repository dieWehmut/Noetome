[4] 关键坑
用 MSYS 形式 `PATH="/d/tools/pwsh7:$PATH"` 时，Windows 的 python 看不到 pwsh，
`shutil.which("pwsh")` 返回 None，只会跑 powershell 一类；必须用 `PATH="D:\\tools\\pwsh7;$PATH"`。
另一处：MSYS 的 unzip 不存在、`python3` 也不存在（exit 9009），解压只能借用 Windows 的 Expand-Archive。

[5] 计数口径
作者报告写「两 PowerShell 各 39」，本机每个引擎实际 16 个 test 方法；39 应是断言/检查计数，不是方法数。
