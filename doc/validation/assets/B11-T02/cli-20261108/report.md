## 边界

- 正文保持干净：索引不插入文献编号、脚注或出处列表，人工新增文字也不会自动获得来源。
- 来源按内容摘要识别，不按文件名：同名但内容不同不算同一份来源，缺失时只提示需要重建映射，不指向任何页面。
- 运行库、缓存、临时文件与凭据不进入输出区与索引；模型调用与网络请求 0 次，不判断内容质量与科学正确性。
