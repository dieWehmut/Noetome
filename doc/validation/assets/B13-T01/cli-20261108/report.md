# 规模实测（scale-synthetic-v1）

这是**合成语料**的实测：页面由参数生成，不含任何真实教材内容，也不证明真实教材的抽取质量。

## 参数

- 页数 8；每页标题 2；每页段落 2

## 结构产物

- 页面 8、字节 4708、文本片段 96、标题 16、段落 32、概念 8、出现 80、对齐警告 0

## 实测

- 耗时与峰值内存写在 `timings.json`，本文件不复制它们：报告是摘要产物，
  必须与结构产物一起保持逐字节确定，任何挂钟读数都会让同一参数两次运行不再相同。

## 规划上限（未达标项）

- 结论：not_met
- 上限：topics=4、goals=8、concepts=64、atoms=256
- 规划动词的声明上限是 topics=4、goals=8、concepts=64、atoms=256；千笔记、万原子的规划在本轮无法达成。本 harness 只证明文本分析与章节对齐在千页规模可用，不把页面处理当成规划已经达标。

## 边界

- 结构产物只由参数决定，两次同参数运行的字节相同；耗时单独成文件，不参与确定性比较。
- 页面是合成的，不证明真实教材的抽取质量，也不代表科学正确性。
- 不联网、不调用模型、不写项目与 Vault；本阶段不生成知识。
