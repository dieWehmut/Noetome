## 两项网络测试的修复与反例

生产超时、预算、网络和 `shutdown_background()` 行为保持原值。仅测试增加客户端实际接收正文的观测：取消在收到 `abc` 后触发，不把 server accept 当作 client 已收数据；未完成响应由 release gate 保持，超时 fixture 留出客户端初始化的时间。

后台 worker 通过 channel 确认启动并等待 release。`send` 返回时 worker 必须仍未完成，然后释放并确认退出；3 秒 fallback 使错误实现有界失败。默认并行 transport 模块连续三次 8/8 通过，真实退出码均 0。独立临时源码副本改成同步 `drop(runtime)` 后，测试在 3.06 秒按顺序断言失败，真实退出码 101，无死锁；工作区源码指纹前后相同。见 [通过记录](assets/B15-T01/transport/fixed-default-results.json)与[反例记录](assets/B15-T01/transport/synchronous-shutdown-negative-results.json)。
