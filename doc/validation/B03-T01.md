## 实现产物与边界

[协议v1](../technical/SIDECAR_PROTOCOL.md)及[实施计划](../execution/B03-T01_PLAN.md)固定输入、状态、资源、限额和工程裁定。Rust sidecar Host 建立自有快照和独占根；strict DTO 只接受命名对象与字符串枚举；原生平台模块负责 Windows Job、三个管道端继承、观察、终止和有界等待。CLI/desktop 的 unsafe forbid 保留，只有独立小平台 crate 的私有 Windows 模块允许审查过的 FFI。

单请求是原始字节 identity 协议，fake 明确 producer=fake / protocol_only。测试 target 为 harness=false，私有 helper 用受信测试 argv 自入口，普通 CLI 没有 fake/sidecar 命令。没有接真实 PDF、Python 解析库、OCR、模型、项目登记或 GUI；原有来源 Schema2、编译 Schema1及已验收安装版均没有改。

默认输入64MiB，请求64KiB，stdout4MiB，stderr256KiB，单资源16MiB/总64MiB，单元4096、资源64、问题128；运行30s、清理2s。公开调用只收紧政策。数值是限额，不是吞吐、科学质量或1000页基准。

## Windows生命周期和环境实测

真实子/孙握手带nonce、PID和创建时间，独立观察器先确认活跃，再并发wait/drop。六个进程树探针覆盖 timeout、cancel、stdout/stderr超限、根提前exit0但孙持管道及无管道孙；观察到根/孙真实退出，不能用PID名称消失代替。进程准备阶段before-Resume故障实际杀死根exit1，未恢复用户代码；准备清理使用调用者收紧的期限。

初次新工作区构建及测试写入失败对应Low程序与新生成目录标签不匹配。仅对自有target、desktop/gen、.artifacts生成目录设置Low后，原247项基线通过；原D盘用户删除保留。没有修改系统或生产资料的目录权限。

完整Host env对照：spawn返回3.4435ms，helper用户入口约10.823s，总10.834s；只移除TERM后spawn1.8889ms，整次23.5521ms。TERM是本私有libtest场景的触发变量，底层机制未确定。execute只传现存SystemRoot，不扩大任何预算，也不传其他Cargo/terminal/parser设置。

真实准备失败探针发现 query/synchronize 观察句柄仍存活时Job活动数已归零。原“任何引用必阻止归零”断言为错误预期，不计产品红。保守及时释放句柄仍保留，依据实际Job计数及独立退出状态验收。

一次25组矩阵的真实abort仍在5s期限内未结束，正确返回TIMEOUT；不改代码单独重跑又EXIT_NONZERO。匹配本轮测试PID的Application1000/WER1001同ReportID事件间隔11.58s；另一次独立观察获得0xC0000409、自然等待2.505s。当前Rust x64 abort是int0x29 fast-fail，非CRT abort，未用_set_abort_behavior冒充修复；依据[锁定Rust源码](https://raw.githubusercontent.com/rust-lang/rust/48a229ceaefd4985c50990b14116b6d856af0985/library/std/src/sys/pal/windows/mod.rs)。最终仅私有crash helper自调用本进程SetErrorMode保留其他bits并启用SEM_NOGPFAULTERRORBOX，以及WerSetFlags NO_UI，成功读回；父进程快照和注册表不变。原std::process::abort、5s预算、字面异常退出码都保留。首个策略查询未注册返回NotFound属于setup失败，不解释为配置成功。策略stub实际child101vs0红后平台6/6绿；启用后的定向真实abort观察121.687ms、0xC0000409、EXIT_NONZERO/responseNone，定向矩阵约132ms，最后workspace回归实际124.1663ms。本轮未观察到可见弹窗。详见 Microsoft [SetErrorMode](https://learn.microsoft.com/en-us/windows/win32/api/errhandlingapi/nf-errhandlingapi-seterrormode)、[WerSetFlags](https://learn.microsoft.com/en-us/windows/win32/api/werapi/nf-werapi-wersetflags)。
