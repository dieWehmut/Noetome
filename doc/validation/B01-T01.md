## 本轮修复记录

1. 首次在锁文件尚不存在时使用 `--locked`，Cargo 拒绝创建锁文件，退出码 101。随后显式执行 `cargo generate-lockfile --offline`，其后锁定、离线检查通过。
2. 首轮 CLI 测试通过 `std::env::temp_dir()` 选择系统临时目录，4 项均在创建工作区阶段遇到 Windows 错误 5（PermissionDenied），未进入 CLI 行为断言。改用仓库构建目录下的独占测试目录后，4 项实际通过。
3. 修改测试目录代码后首次格式检查发现一处换行差异，执行 `cargo fmt --all` 后格式检查通过。帮助实跑发现选项缩进被 Rust 字符串续行消除，改为保留换行和缩进的字符串，再运行格式、构建、测试和新目录构建通过。
