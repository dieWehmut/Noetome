# B09-T03 验证记录：个人版打包配置与安装后验收清单

## 1 范围与依赖

本任务把「个人版怎么装、装完怎么验」变成可复现、可审计、可交接的两件产物，并冻结打包面：

- `crates/noetome-desktop/packaging-frozen.json`：打包面 10 个成员的 SHA256 与字节长度（发行前每次改动都必须显式重冻结）。
- `doc/standards/DESKTOP_ACCEPTANCE.md`：安装后人工验收清单（9 节 40 余条），明确静态检查与浏览器预览不能替代安装后测试。
- `scripts/verify_desktop_package.py`：独立只读打包审计器（不 import Rust、不跑 `tauri build`），重算上述期望并比对冻结清单。
- `tests/test_verify_desktop_package.py`：审计器自身的 34 项反例测试（篡改配置、图标、权限、CSP、构建产物各自必须报错）。

依赖 B09-T01（项目入口）与 B09-T02（任务中心只读投影）已验收；本任务只收紧打包与验收，不新增运行期能力。关联需求：NFR-16（记录最低支持与当前稳定 Obsidian 版本）、NFR-17（可导出日志与分页批处理）、AC-39（长任务 24h 与睡眠恢复）。本任务不重复验收科学正确率、真实资料导入、通用 OCR 与规模门槛。

## 4 关键取舍

1. **审计器不执行 `tauri build`。** 本环境没有 Windows 目标与 NSIS，跑构建只会产出 Linux 二进制并给出「成功」的错觉；审计器改为重算打包面的可判定属性（installer 目标、安装模式、安装器语言、图标字节、权限命名空间、CSP 来源、构建产物形态、命令面）。
2. **打包面冻结而非「检查配置就算」。** 冻结清单把 `tauri.conf.json`、`capabilities/main.json`、`icons/manifest.json`、5 个图标、`package.json`、验收清单绑成一组；任何一处漂移都会同时产生 `frozen-digest` 失败，迫使改动被显式记录。
3. **权限只允许 `core:window:` 与 `core:event:`。** 桌面至今没有文件、网络、进程插件权限；审计器对 `dialog:`/`fs:`/`http:`/`shell:`/`process:`/`upload:`/`download:`/`websocket:`/`os:` 直接判失败，防止「顺手加一个 dialog 插件」绕过受限命令面。
4. **CSP 必须只连 IPC。** 断言 `default-src 'self'`、`connect-src ipc:`，且剥离 `http://ipc.localhost` 后不得残留任何 `http://`/`https://` 来源；`style-src 'unsafe-inline'` 保留（React 内联样式所需），在契约里如实标注为已知放宽项。
5. **缺失构建产物是「提示」不是「失败」。** 干净克隆尚未 `npm run web:build` 时 `dist/` 不存在；审计器记为 warning 并输出「先运行 npm run web:build 再审计」，避免把「还没构建」误报成「配置错误」。
6. **验收清单写死「静态不能替代安装」。** 清单第 9 节判定规则：全部条目实际执行并留证才算通过，否则必须写「部分通过」并逐条列出未运行项；第 8 节明确排除科学正确率、真实资料导入、通用 OCR、规模与 Obsidian 兼容矩阵。

## 8 仍未闭合

1. **Windows 原生 NSIS 安装包未产出、未安装、未卸载。** 本机 `rustup target list --installed` 只有 `x86_64-unknown-linux-gnu`，`makensis` 不存在；`bundle.targets = ["nsis"]` 在本环境无法执行。清单 1.x/2.x/6.x/7.x 全部条目均为「未运行」。
2. **`cargo build --release` 产出的是 Linux 二进制**（18 040 496 字节），只证明桌面 crate 能在 release profile 下编译链接，不证明 Windows 打包可用。
3. **验收清单没有被真人执行过。** 清单本身是产物；`DESKTOP_ACCEPTANCE.md` 的 40 余条目前没有任何一条有执行记录。
4. **`style-src 'unsafe-inline'` 仍是已知放宽项**，未改为 nonce/hash 方案。
5. **图标源文件（1254×1254 PNG）不入库**，只入库 `icons/manifest.json` 记录的源摘要；无法从仓库独立重跑图标转换。
6. **`gen/schemas/` 与 `capabilities/main.json` 的 `$schema` 指向未纳入冻结清单**，Tauri 版本升级导致 schema 变化时审计器不会报错。
7. **本任务不验证科学质量、真实资料导入、通用 OCR、千页/万原子规模与 Obsidian 兼容矩阵**，也不宣布个人版发布或生产可用。
