# B06V-T01 明确图像保真验证记录

本项验证公开自造整图 PNG 与作者手工结构声明的有界工程表达，输入与结果不代表自动图像理解、OCR、真实实验数据或科学正确率。任务事实状态仍见[账本](../../dev-log/tasks.json)。[图像契约](../technical/IMAGE_FIDELITY_CONTRACT.md)与[作者素材](../../fixtures/image-fidelity/README.md)限定本次范围；扫描公式与跨版本矩阵分别由后续两项验收。

## 作者原件与实际 RED

独立作者先用 Pillow 按手工像素坐标绘制公开 CC0 PNG，另外记录元素、方向/正负、单位、图例、空间、条件与例外，冻结 expected。普通 CLI 仅消费所选三个文件和 profile，不读 expected。最终 `frozen-sha256.json` SHA256 为 `b74d28cc98598f53d5efbf47bacdab9aa80bb23f938ffb2537c3a2f7c072af1e`，包含12个场景。

真实旧 CLI 在支持来源准备完成后退出2/CLI_INVALID_ARGUMENT，新 Vault 不存在，原件和哨兵未变。第一版作者 PNG 的关系长标签贴近节点，独立视觉读回发现后修正作者排版，再冻结并重新取得 RED；第一版不能算清晰原图验收。两轮作者与普通 RED 原件均保留在[独立历史](assets/B06V-T01/independent/history.md)、[归档指纹](assets/B06V-T01/independent/archive-sha256.json)及对应 ZIP，未删除失败记录。

## 实现与独立检查范围

`knowledge image` 读取明确 PNG、作者语义和能力 profile，完整解码验证 CRC/尺寸/EOF，持有原件/祖先/库存并重验。有限 SVG 保留源坐标、标签、方向/正负、单位和图例；已知不支持的几何、不能保真的布局或未验目标使用原图。曲线和观测保持原图，关键未知、不可辨和矛盾几何阻断。成功与阻断始终留存原 PNG、原 case/semantics/profile 字节；只有成功结果另存计划和预览。

[独立校验器](../../scripts/verify_image.py)从冻结作者重验实际 SVG 图元/箭头 polygon、正文对象与字段关联、字面特殊字符、原件、完整 UTF-8 映射、计划、双报告壳及库存。同步更新文件、映射、计划和两报告指纹的伪造须因实际含义或作者来源不符被拒绝；修改手工源声明重新编译后的结果也须对照原冻结作者拒绝，不能把自报新 SHA 称为作者真值。

测试覆盖严格 nullable/类型/重复键/引用/三文件库存、损坏/截断/尾随 PNG、目标回退、原图留存、未知与矛盾阻断、普通新 Vault、路径碰撞、输入/祖先链接、持有期修改以及失败清理。人工修改的 SVG、未知输出与外部哨兵保持原样；仅撤去本轮可确认的成功结果。早期格式命令在 guard 模块尚未创建时无法解析；后续在源码齐备后重跑，不能把准备期失败当作最终通过。

## Obsidian 原生依据

[能力探针](assets/B06V-T01/native/probe-review.md)使用独立测试 Vault/profile，实际安装 Obsidian 1.6.7、Electron 30.1.2、Chromium 124.0.6367.243，安装 exe SHA256 为 `2156f15d12da8cc292fe0cc1884f32410fa187fede67beb6102cfcdc6442fbe2`，community plugins 为空。探针真实加载本地 SVG/PNG，并实际点击原 PNG 附件。

Obsidian 以外部 img 加载 SVG，笔记 DOM 不提供内部图元；同一已确认应用实例的自有临时 BrowserWindow 打开同指纹附件，采集真实 SVG 文本/图元几何，再与笔记原生 canvas RGBA 相等联结。探针五次运行中的 CDP/XML DOM/canvas/screenshot 技术失败全部归档，修复采集方式后成功；探针只证明环境能力，最终 CLI 输出须另行实测。

原生深色主题随后真实发现产品 SVG 透明背景问题：透明版本普通 CLI 成功，但实际应用背景为 `#1e1e1e`，960×520 的499200像素中382726非不透明，左上 RGBA 为 `[0,0,0,0]`。黑色正负标记、关系标签与单位在原生截图中几乎不可读，native capture 退出1。该轮 CLI SHA256 为 `a81020af4f0c1569bd8e176e6d6c0866faa75144350ca640e115f4f1cc7055f6`。失败来自真实加载图像和截图，不把准备脚本或 checker 版本错配当作视觉失败；同期 checker 的后来副本只标为观察版本。修复加入固定完整白画布，并将关系线/箭头按作者原图统一为黑色，图例颜色与正负/归属仍保留；最终浅色及深色输出另行验收。

## 新鲜独立审查与修复

独立审查另外取得箭头头部遮挡第三图形的普通 CLI RED：中心线没有穿过第三形状，但箭头三角形覆盖其角部。Rust 使用 SAT，独立 Python 使用多边形裁剪，均考虑1px stroke 包络；同一补充声明故障探针修复后改为原图回退。故障探针不增加冻结作者样本数，未把修改结构声明称为新的图像理解基准。

[新鲜只读审查](assets/B06V-T01/review/fresh-review.md)随后自造400×250清晰 PNG，黑底以白字显示 Payload/mg 与 Dark/Selected payload。旧 CLI 合法输入退出0/svg_redraw，四个关键 text 与其背景均黑色，实际文字消失。完整真实 RED、原 PNG、手工声明、原件副本和执行指纹见[反例记录](assets/B06V-T01/review/contrast-probe/receipt.json)；旧审查保持原问题未处置时的事实快照，修复闭环另存。

颜色修复保留任意已知 #rrggbb Schema，在有限黑字样式之外用 IMAGE_COLOR_CONTRAST 原图回退，不改原色、不改作者标签/单位、不生成 SVG。每个 RGB 通道191/192边界和黑底反例均增加检查；后续稳定版本在同一源上实际取得原图回退 GREEN。该保守政策不表示通用科学配色测量。

同源 GREEN 与原件核对保存在[修复原件](assets/B06V-T01/review/contrast-green/receipt.json)；root 另以独立校验器确认所有可见正文字段及映射、原 PNG/case/semantics/profile 字节，以及旧不可读实际 SVG 的拒绝，见[闭环记录](assets/B06V-T01/review/contrast-closure.json)。只移除经过 SHA/单链接核对的本轮旧 CLI 临时副本，保留真实执行 SHA、全部输入、stdout/stderr、输出与失败事实；未删除作者或人工内容。
