关键实现取舍：

- **必要性正向单调**：`required(atom) = ∃ lv ∈ atom.levels : level_index(lv) <= level_index(用户水平)`。
  低阶原子在高水平仍然必要（学过大学内容不能删掉定义），反向不成立。高水平只增加必要性，
  所以 `author-advanced.json` 把 `atom-pfk-fret` 变成必要之后，原来那条"超纲"排除就必须被拒绝。
- **排除落在 Span 上而不是行号字符串上**：排除先用 `text_span_covering_line` 找到真实 Span，
  落在标题或空行就报 `RELEVANCE_ARGUMENT`。标题是结构不是可选散文，永远 kept。
- **必要前提是拒绝而不是补齐**：`provided = {kept 原子的 covers} ∪ declared_knowledge`，
  缺任何一个 `requires` 就整包报 `RELEVANCE_PREREQUISITE_MISSING`。静默省略前提比拒绝更危险。
- **先 dry 判定再建根**：`adopt` 先在内存里对每个来源跑 `derive`，全部通过才 `create_dir`；
  语义拒绝不留半成品（四条 rejection 证据文件都记 `left=0`）。
- **两种密度只差 `expansion`**：`comparable` 只取 `(atom_id, conditions, requires)`，
  `unchanged_across_densities` 由这份投影相等算出，而不是由"代码没改原子"这种声明保证。
- **输出清单不含时间戳**：承诺"同一冻结输入的两次构建字节相同"就不能把墙钟时间写进输出文件。
  `control/manifest.json` 仍带 `created_at`（它是建立时刻的事实），输出根的 `manifest.json` 没有。

## 实现过程中发现并修掉的缺陷

1. **`conditions` 被当成标识符校验**：`AtomSpec::validate` 对适用条件用了 `identifiers()`，
   于是「镁离子存在」直接报 `RELEVANCE_ARGUMENT：适用条件只能包含ASCII字母、数字、连字符、下划线和点。`
   这是真实产品缺陷——适用条件是给读者看的散文。修法：新增 `condition_list`，用 `single` 校验
   （非空、无首尾空白、≤600 字符、无控制字符、不重复），只对 `requires`/`covers` 继续用标识符规则。
2. **`control/author.json` 多写了一个尾换行**：`adopt` 用 `format!("{}\n", canonical(...))` 落盘，
   而 `strict()` 逐字节比对 canonical 编码，于是 adopt 成功后任何 `build`/`status` 都报
   `RELEVANCE_INTEGRITY：冻结作者声明非规范编码、重复键或未知字段。` 修法：写成
   `canonical(...)?.as_bytes()`，并在函数上说明为什么不能加换行。（派生输出四文件仍带一个尾换行，
   审计器 `strict_load` 明确允许且只允许一个。）
3. **`build_summary` 把冻结来源标成输出根**：原实现打印 `manifest.source_root` 却配文案"输出根"。
   修法：第一行用 `output.display()`，新增第二行"冻结来源："用 `source_root`。
4. **审计器 `segment()` 漏算换行**：所有 Span 的 `end_byte` 与 `text_sha256` 全错
   （实测 `#0.end_byte: 18 != 17`）。Rust 侧 `split_inclusive('\n')` 让每个片段含自己的换行，
   Python 复刻必须补回。修法是按 `split_inclusive` 语义逐行累加，末尾换行不产生额外空行。
5. **审计器 `expected-atoms` 少比两个字段**：先验条目含 `source_id`/`line`，原实现只比
   `atom_id`/`conditions`，于是先验漂移测不出来。修法：补齐四字段，并新增
   `expected-spans-by-source`、`expected-text-spans-by-source`、`expected-densities`、
   `expected-rejections` 四项检查。
6. **审计器在缺目录时抛 `FileNotFoundError`**：`check_manifest` 直接 `iterdir()`；
   `check_output_manifest` 直接算摘要。修法：缺目录先记一条失败再 return，缺文件先算
   `missing` 列表并给出"缺少 …"。

另外删除了一处死代码 `statement_at`（32 行，从未调用），并把
`exclusions.iter().find(...).map(|(_, (item, _))| item.clone())` 改成 `*item`。

集成测试首跑 15 passed / 2 failed，两处都是**测试期望错**而非产品错：正文实际写
「单分子荧光共振能量转移」而不是缩写；`report["counts"]` 比 `expected["counts"]` 多一个
派生键 `atoms`。前者改断言，后者改成逐 key 比对先验出现的项再单独断言派生键。

   低并发复跑通过。未修，如实记录。
4. **Python 既有失败未修**：41 failures / 12 errors 同上。
5. **不判断科学正确性**：筛选只保证"该保留的没被删、该排除的有理由、前提不缺"，
   不保证原子陈述本身正确，也不保证排除判断在真实教材上正确。
6. **不做自动补前提**：必要前提缺失时拒绝而不是去检索补齐；补齐属于研究任务的职责。
7. **不写知识库与 Vault**：本轮只产出筛选记录与两种密度的编译产物，没有接编译管线。
8. **`level` 只由用户声明**：不从资料推测水平（FR-05 要求推测只能作为建议），
   本轮连"建议"都没有实现，只有显式声明。
