## 原离线阶段的实现及范围

普通CLI新增`extract api <project> <import-id> <config.json> <new-output> [--cancel-file ...]`。配置严格只读，保存身份、mtime、SHA和所选外部环境变量引用；live只允许官方HTTPS Responses，本地模式只允许数字环回、明确端口及noetome-test-人工模型/凭据。不读取默认密钥，不批量调用其他SDK。

native HTTP/wire/Schema与Core分开：一次POST禁用客户端代理继承、重定向和重试，实际正文、收取字节及时间有界。Core在请求前预留完整正文UTF8字节加1024与输出上限，在返回后核对实际整数用量、细项和总预算；价格、tokenizer及无法核实的计费保持null。金额预算且价格未知时不请求。预留是工程策略，不是提供商Tokenizer测量或账单保证。

请求绑定真实project/import/source/version/SHA及选定资源位置。API候选与fake共用领域校验，但不转成fake DTO；非零起点anchor复制原资源字节范围。API owner、候选包装与双报告明确producer/transport_mode。正常原响应保持原字节；普通、转义、嵌套或非法JSON中的凭据回显在保存前拒绝，省略原文并保留收取长度/SHA。完整200的有效元数据/用量独立于候选、refusal或incomplete核对。

来源、所选配置和输出能力贯穿保存及最终重查。已有输出拒绝，失败只撤回持有的候选/结果报告，不删除未知人工文件；来源SQL、历史字节、mtime和清单保持只读。所有候选仍unverified、知识pending、published=false、scientific_quality=not_run，不登记KnowledgeIR、Run、Release或生产Vault。
