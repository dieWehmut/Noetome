# 真实来源持久编译契约

B16-T03从已验收的`corpus`消费真实页版本，新增`production_compile` Application。旧fixture、人工环回运行器与单请求抽取保留原入口和独立预期。本文说明实现边界，不作为通过证据。

## 输入与范围

项目选择一个或多个已登记来源，范围明确为全部物理页。准备阶段按页保存原件SHA、页JSON原字节SHA、页状态与UTF-8片段；单请求通过片段大小、输出Token和期限限制，不能截断全书范围。空白、待OCR、解析失败、无候选与已确认知识分别计数。源库更新其他页不使整份DB字节SHA成为所有任务的失效依据。

证据绑定不可变来源版本、物理页号、固定页SHA、UTF-8半开区间、原文和摘要。读取使用当前或历史页的原SHA，不从解码后JSON重新序列化推造旧摘要。来源与资产缺失或篡改明确拒绝。知识候选始终未核验；解析问题、图示和科学未知不因模型返回JSON消失。

## 身份与知识

生产概念、原子、证据与笔记使用应用持久生成的UUID和正整数修订，模型局部ID只用于本次响应映射。同一已确认批次重开不重新生成身份或重复确认。纯领域校验与旧fixture共用；来源绑定、证据原文和生产来源状态由生产入口另验。

没有足够语义依据的跨批同名概念保持独立候选，保留待协调问题，不只凭名称自动归并。笔记按设计规范默认使用简体中文解释与概念名称，必要原文术语保留为别名；固定证据引用、条件/公式/单位原文不翻译或规范化。语言要求须在真实英文来源输出中实际检查，prompt本身不作为通过证据。笔记保留概念、事实、完整条件/单位、逻辑顺序和明确未解决范围。正文不加入逐句文献编号；独立索引保存笔记块、原子、证据和页版本映射。生产IR以SQLite分页保存，不能要求整本知识全量载入内存才能查询或恢复。

## 请求与预算

复用用户已授权的服务、模型、DPAPI引用和累计10M Token。现有外部JSON历史只读固定，生产预算权威显式迁移至同目录SQLite，保存全部旧记录、原字节和摘要。迁移后原账本设为只读，原字节和完整旧历史保持；禁止缺失权威时自动创建新余额；旧真实JSON调度入口在迁移标记或只读属性存在时拒绝，避免同一额度发放两次。

每批先持久保存attempt和实际请求，再原子预留，确认可发送后记录`sent`，最后保存原响应/传输回执、结算有效usage并确认IR。确认用量大于预留时如实记超量并停止新请求；未知保持预留，不因暂停、终止或重开退款。认证、限流、传输或候选协议失败后停止新批次，原件和用量继续保留；普通重开或运行保持failed与原停止理由，显式retry后才重新排队；合法空候选留下未解决片段并继续后续页。价格未知保持null。重复结算只有相同请求身份、回执和用量才幂等。

请求限定同一已授权文本端点与模型；人工环回只在明确测试模式使用。模型材料不能改变工具权限，模型没有工具执行能力。凭据只在选定worker内存/环境传递，不进入参数、源码、索引、原响应或日志。单请求有独立期限，不设整本短超时。

## 恢复与输出

数据库身份守卫与SQLite锁协议共存。Unix对数据库及journal/WAL/SHM只做无打开句柄的路径、类型、硬链接数与dev/ino核对，不额外open/dup/close同一inode；Windows继续持有阻止删除替换的句柄。POSIX关闭同一进程中该inode的任意描述符会释放文件锁，额外的普通文件守卫可能让另一个连接误判最后用户并删除仍使用的WAL/SHM，见[SQLite官方损坏原因说明2.2](https://www.sqlite.org/howtocorrupt.html)。回归以独立进程实际竞争写锁、控制提交关闭后页文件身份保持和第一连接立即读到暂停要求验证，元数据检查本身不替代SQLite事务锁。

暂停和取消请求持久保存，停止新调度；在途完成未知时保留预算与attempt。重开已有完整原响应可继续验证和确认，不重复网络请求；缺回执的已发送attempt标为未知，显式重试另建attempt并保留旧预留。已确认知识与历史页不重写。

查询按概念/原子/证据/问题及全部页范围/片段分页，并可回到固定原文页；未准备页保留unprepared与null页SHA，已准备但未确认或失败片段计入未解决页，分母不因暂停缩小。输出仅写不存在的新测试Vault，保留清单、来源索引、知识状态和未处理问题。页与片段NDJSON完整列出未处理位置；export-manifest.json记录除自身外全部导出文件的实读摘要和字节数，成功前保留incomplete标记。导出后重读所有声明文件，已有目的地拒绝且不改原件。原件打包属于明确选择，不自动复制私人整书。安装版须用本次程序与安装器字节完成真实原生按钮、选文件器、暂停/重开、导出与Obsidian阅读；开发程序或fake不能替代。

科学200原子/98%、复杂图示全语义、任意断电与24小时门槛保持各自验收范围。0.2测试版必须列出本次实际完成和未知范围。

### B17 本地 OpenAI 可选 provider

云端 `live` 的 deepseek-flash 白名单及 60000ms / 8192 tokens 上限保持。
显式 `transport_mode=local_openai` 接受带端口的 HTTP 127.0.0.1 或 localhost，路径固定 `/v1/chat/completions`，拒绝用户信息、查询及 fragment；模型名非空。
本地必须 `credential_mode=none`、`credential_env=""`，请求不带 Authorization。旧云端配置省略 credential_mode 仍兼容 env；显式值仅接受 env。
本地 timeout 为 1..=300000ms，输出为 1..=32768 tokens；建议初测 180000ms、4096 tokens、2048 bytes，属于测量起点而非性能验收。
本地账本文件名固定 `local-openai.usage.json`，使用独立目录中的已有授权 JSON 基线；派生 `.production.sqlite` 与 authority marker 由现有预算机制创建，绝不创建 JSON 余额。不得把云端历史复制为本地额度。缺失基线报 `LOCAL_PROVIDER_LEDGER_MISSING`，名称不符报 `LOCAL_PROVIDER_LEDGER`，内容损坏仍返回生产预算完整性错误。
`reasoning_effort` 可选 none/low/medium/high，请求同时保留 thinking disabled。服务是否遵守需实测。标准 completion_tokens 已包含 reasoning_tokens；校验细分不超过 completion 后，按 total_tokens 结算，不重复累加。缺少或不合法 usage 保留未决预留。
独立诊断 `scripts/measure_local_provider.py` 仅消费显式选定 UTF-8 页文件，输出 JSONL 耗时、quote_exact 与 usage；不操作生产预算或证明生产 schema/科学质量。生产 fake HTTP 回归另行覆盖持久编译结算。
