# Noetome 产品交互与输出设计标准

本文件固定 Windows 桌面端、CLI、报告与 Obsidian 输出的设计。产品行为依据 [PRD](../requirements/PRD.md)，配置依据 [CONFIG](../technical/CONFIG.md)，命令与状态依据 [RUNTIME](../technical/RUNTIME_PROTOCOL.md)。完整设计不代表已实现；每项能力仍按执行任务逐步交付并验证。

## 1 设计目标与实现边界

用户应首先理解本轮实际结果、产物和待处理事项，再查看资料、推理过程及运行细节。产品不显示一个没有分母依据的综合百分比，不以漂亮笔记掩盖失败、不确定性或人工冲突。

桌面端采用 Tauri 与 React TypeScript，调用同一core命令和事件接口。数据与工作状态由core提供；前端不得根据计时器、Toast或本地缓存自行判断生成或发布成功。完整Markdown编辑器、插件商店和多人协作不属P0。

## 2 桌面信息架构

默认窗口为1440×900逻辑像素，最小1100×720。窗口小于默认值时收起辅助侧栏，保留主操作与状态；所有主要流程在200%缩放下仍可滚动使用，不能裁切按钮。

采用左侧全局导航、顶部项目与运行状态、中间内容区、可折叠右侧证据或细节栏。左侧宽224，折叠后64；右侧默认360、可拖动到320至600。侧栏尺寸为用户偏好，不影响项目配置。

| 一级入口 | 核心内容 | 主要动作 | 必须覆盖的状态 |
| --- | --- | --- | --- |
| 项目 | 最近项目、主学科、最新发布、未完任务 | 新建、打开、继续、归档 | 无项目、路径缺失、版本不支持 |
| 资料 | 文件与版本、页和图表清单、来源状态 | 添加、换版、定位、局部重试、移除 | 上传中、解析中、失败、加密、缺失 |
| 生成 | 范围、深度、风格、模型、预算、权限摘要 | 预览计划、开始、保存配置 | 缺配置、能力不足、无有效来源 |
| 任务 | 阶段、队列、在途请求、消耗与近期事件 | 暂停、继续、取消、重试 | 运行、等待、预算停止、恢复、失败 |
| 知识与结构 | 主题、概念、笔记计划、规范位置 | 搜索、锁定、查看引用、审查结构变更 | 空模型、候选、冲突、未分配 |
| 笔记 | 渲染预览、文件树、来源侧栏 | 打开Vault、看原文、看发布版本 | 未生成、候选、已发布、映射过期 |
| 审批 | 人工差异、严重问题、证据与依赖 | 接受、拒绝、局部采纳、编辑候选 | 待审批、已拒绝、已采纳、已失效 |
| 研究 | 范围内目标与范围外候选分别列出 | 接受候选、拒绝、延后、继续 | 未批准、已批准、执行中、未达成 |
| 发布与报告 | 四维完成状态、版本、范围、问题 | 导出、打开结果、比较、回滚 | 部分结果、待恢复、已发布 |
| 设置 | 提供商、数据位置、保留、外观、诊断 | 测试连接、管理凭据、导出诊断 | 无密钥、端点错误、资源不可用 |

全局导航不同时显示全部工程字段。ID、哈希、提示词版本、预算预留和协议原文放在详情；用户启动任务无需先理解Knowledge IR或SQLite。

## 3 核心屏幕与动作约束

### 创建项目与生成配置

新建使用三个连续区块：资料与学习目标、生成与风格、模型与执行。默认展开必要字段，高级配置可折叠，但启动摘要始终显示选定来源、模式、外部检索开关、远程数据目的地、图像/风格样例外发范围和预算。

主按钮为“开始生成”，配置未满足时禁用并在相关字段旁解释。不能只弹出“操作失败”。已有明确配置的相同调用范围不逐请求重复确认；改变端点、发送种类、输出管理范围或费用上限时必须呈现变化。

风格预览使用同一组知识，显示极简、详细、自定义的差别。样例中没有发生真实推理时明确标注预览样例。目标学科、知识水平与风格分别保存，不能把“极简”展示为“减少必要知识”。

### 任务中心

顶部为执行状态、主操作和本轮范围；第二行为资料覆盖、知识编译、质量验证、可选研究四张状态卡；下方为当前主题、阶段、队列、消耗和事件。每张状态卡都能打开分母及失败明细。

进度显示已完成数、待处理数和已知总数。研究增加候选或重新规划增加工作时说明原因，不为保持单调上升而改写数字。ETA没有依据时显示“尚无法估算”；任务无有效进展时显示等待网络、输入、预算或恢复，而不是无限“处理中”。

取消必须区别于暂停。暂停保留继续能力并停止新派发；取消让未完成工作退出本轮，保留已发布版本。暂停、取消和已结束均不自动将质量状态改成完成。

### 来源与笔记联动

中间显示候选或发布笔记，右侧根据选中的章节、内容块或图元素列出支持、反驳、限定证据。点击证据打开原始PDF页及区域或文本范围，页码同时区分物理页与印刷页。

候选预览顶部固定显示“待发布候选”和所属版本；不能与已发布内容混用同一无标识标签。外部编辑后映射失效时显示“来源映射需要重新匹配”，不模糊高亮近似段落并宣称精确定位。原文件缺失时仍展示来源描述和已保留证据，提供重新定位入口。

### 审批中心

列表按影响类型和主题聚合，默认先显示人工编辑风险与阻断级问题。每项展示当前、候选及可展开基准，说明变化理由、证据、受影响引用、资产和目录。

接受操作绑定指定变更集合指纹；提交前core重新校验当前文件。过期后按钮失效并提示重新比较，不能点击旧Toast继续应用。拒绝保留历史，重试不自动重新应用。批量接受只适用于用户明确选中的同类变更，不隐藏逐项差异。

普通审批自动模式不撤销人工保护。受影响对象及依赖暂缓，其他独立任务继续；用户不处理某项时允许交付明确的部分结果，不显示“全部更新成功”。

### 发布与研究结题

报告先显示已发布范围、四维结果及未完成原因，再显示统计与细节。未批准研究候选独立列出，不计入本轮已批准目标分母；已批准必需目标失败不能改名为候选。

回滚入口先生成变更预览，展示发布后人工改动及恢复范围；回滚受同样审批和写前指纹检查约束。删除项目记录、原文件、缓存与Vault分别作为不同动作。

## 4 运行与后台状态

Run状态使用以下映射；前端不能引入与core不同的同义状态。

| core状态 | 展示 | 可用主要动作 |
| --- | --- | --- |
| draft | 配置中 | 保存、补充资料 |
| ready | 就绪 | 开始 |
| running | 运行中 | 暂停、取消、查看进展 |
| pause_requested | 正在安全暂停 | 查看在途请求、取消等待后的强退说明 |
| paused | 已暂停 | 继续、取消 |
| cancel_requested | 正在取消 | 查看保存状态 |
| blocked_input | 等待输入 | 查看所需输入、继续独立工作 |
| blocked_config | 配置受阻 | 修正具体配置 |
| budget_stopped | 预算停止 | 查看剩余、调整预算后继续 |
| failed | 执行失败 | 查看原因、局部重试 |
| cancelled | 已取消 | 查看已保留结果、另建运行 |
| ended | 执行结束 | 查看四维结果、发布与研究报告 |

Release为staged、verified、publishing、published、recovery_required、rolled_back；分别显示“暂存候选”“校验通过”“发布中”“已发布”“需要恢复”“已回滚”。verified不意味着已发布；publishing期间显示实际步骤且不允许重复发布。

每项目按需启动worker，桌面和CLI通过统一接口控制。关闭窗口首次提供“托盘继续运行”和“安全暂停后退出”并允许记住选择。托盘保留状态、打开、暂停和退出入口；只有确实运行时才标示后台运行。

安全退出停止新派发，等待在途结果和落盘，关闭worker后退出。30秒未结束显示具体等待项；强制退出需说明远程请求可能继续计费和结果未知，恢复时进入对应未知状态。关机、崩溃、睡眠和网络切换不假造成功。应用不安装常驻OS服务、不默认登录自启动，不自动阻止系统休眠。

## 5 设计Token与组件

所有前端颜色、间距和字号引用主题token。以下为起始固定值；调整需通过对比度和缩放回归，不允许单页随意硬编码。

| token | 浅色 | 深色或取值 |
| --- | --- | --- |
| background | #F5F7FA | #111827 |
| surface | #FFFFFF | #1F2937 |
| text.primary | #17202A | #F3F4F6 |
| text.secondary | #52606D | #CBD5E1 |
| accent | #2457C5 | #93C5FD |
| status.success | #166534 | #86EFAC |
| status.warning | #92400E | #FCD34D |
| status.error | #B42318 | #FCA5A5 |
| border | #CBD5E1 | #4B5563 |
| focus | #2457C5 | #93C5FD |
| spacing | 4、8、12、16、24、32像素 | 双主题一致 |
| radius | 输入与按钮6、卡片8像素 | 双主题一致 |
| font.body | Segoe UI、Microsoft YaHei UI、sans-serif | 正文14，内容阅读16像素 |
| font.mono | Cascadia Mono、Consolas、monospace | 代码13像素 |
| type.scale | 12、14、16、20、24、32像素 | 标题最多3个视觉层级 |

基础组件固定为Button、Input、Select、Checkbox、RadioGroup、Tabs、Dialog、Drawer、DataTable、Tree、StatusBadge、ProgressSummary、DiffViewer、EvidencePanel、IssueList、EmptyState、ErrorState、Toast、CodeBlock。优先使用已确定组件体系，组件不封装隐藏业务决策。

按钮分主、次、文本和危险四类。一个区域只有一个最主要动作；忙碌状态阻止重复提交但仍允许查看详情。确认框不能只有颜色差异，危险动作写出对象和影响。Toast用于短反馈，不作为保存错误、审批或失败状态的唯一载体。

表格使用语义表头；大数据虚拟化或分页，不一次渲染3000篇全文。排序和筛选状态可见，空值、未知和不适用分别展示。树节点键绑定稳定ID，目录重命名不能丢失选择或使用户定位到另一个概念。

## 6 可访问性与键盘

产品验收要求普通正文对比度至少4.5:1，较大文字和非文字交互边界至少3:1；颜色必须配合文字或形状表达。token只是设计输入，最终实际组件和状态仍需测量。

所有主要动作可通过键盘完成，焦点始终可见，Tab顺序随可见结构，模态框管理焦点并在关闭后返回触发控件。普通目标点击区至少32×32像素，主操作高度40像素。键盘列表、树和表格不能困住用户；Escape关闭可关闭的对话框，不默认取消整个长任务。

文本允许200%缩放；长公式和图表可单独滚动、放大、查看原图。尊重减少动态效果偏好；动效不承载唯一状态。异步状态变化使用适当的可访问性通知，长日志不逐行抢占朗读。

默认快捷键：Ctrl+K全局查找，Ctrl+F当前内容查找，Ctrl+Comma设置。涉及暂停、发布、删除或审批的快捷键不提供无提示单键动作。用户焦点在编辑字段时不吞掉正常编辑快捷键。

## 7 CLI与机器可读报告

CLI参数使用稳定英文，帮助和诊断默认简体中文。标准输出为结果或显式JSON，标准错误为诊断；JSON模式无颜色、进度条和额外文本。路径作为独立参数，不拼成可执行命令。

公共退出码为0成功、2输入或契约错误、3等待或未完成、1内部执行错误、130用户中断。异步命令返回0只表示请求已接受，输出必须写accepted及run_id；等待命令按最终执行结果退出，不能把受理等同完成。具体命令名以RUNTIME为准。

JSON报告与Markdown报告由同一结构生成，四维字段分别为source_coverage、knowledge_compilation、quality_validation、optional_research，每项包含status、required、total、done、reason_codes、release_id。status只允许complete、incomplete、not_applicable。分母为零不得自动变成“不适用”：仅满足数据契约的不适用条件时这样显示，例如未批准任何研究目标；来源缺失或质量检查未运行应显示阻断或未完成。

错误含稳定error_code或rule_id、对象、字段路径、影响和可执行恢复方法。摘要含producer、来源范围、实际状态、验证与未运行项、产物及报告路径。不得默认打印认证头、完整私有原文或密钥。fixture结果使用“fixture编译验证通过”，不得使用“AI已完成教材学习”。

## 8 Obsidian Markdown输出规范

实际输出文件为UTF-8，路径使用Vault相对路径和斜线。章节层级、标签、Properties、引用和附件从结构化计划生成；模型不能猜文件名或直接决定绝对输出路径。

- 标题连续且语义明确；同类笔记使用相同组织习惯，篇幅不设机械硬上限。
- Wikilink支持文件、标题、块、别名；同名目标使用明确路径。表格内别名分隔符正确转义。块ID合法且在文件内唯一。
- 同一概念只有一个完整解释位置；短上下文事实、派生表格和同源嵌入可以复用，更新后核验全部派生内容。
- Properties仅放轻量且有类型的字段。正文来源默认隐藏在独立索引，争议状态、条件和例外仍可见。
- 表格保留单位、缺失含义、条件和例外；宽表拆分或配套正文，不删除信息。
- 数学采用MathJax兼容表达，已有TeX原文与显示表达分存；扫描公式保持重建来源和待核验状态。语法可渲染不等于数学正确。
- Mermaid使用已验证的图型和版本；不支持的图型回退SVG或列表。图内部链接不代替正文知识链接。
- Callout用于说明、例外和复习重点；不把所有内容塞进折叠块。折叠后不能隐藏唯一必要限定。
- 图片和SVG使用本地资源路径及可读替代描述。复杂原图重绘失败回退原图；真实实验曲线无数据不伪造精确重绘。

应用内预览使用同一Markdown语义节点和受限制渲染器，禁止任意HTML脚本、外部资源自动加载、SVG脚本和不安全链接协议。点击本地资源经路径校验，外部链接由用户明确打开。Obsidian安装中的真实语法、图表和链接验收是独立门禁，不能用应用HTML截图替代。

## 9 设计验收

每次改变用户行为时检查：空状态、加载、错误、等待、取消、部分成功和完整成功是否分别可用；状态是否来自core；失败是否可定位；候选是否被误显示为发布；后台行为是否与选择一致；键盘、缩放、对比度是否通过。

桌面交付至少保留项目创建、长任务、证据定位、审批失效、恢复和发布报告六组场景证据，覆盖浅深主题与中文长内容。截图只证明视觉表现，不证明预算、文件保护或后台成功；最终门禁见 [测试标准](TESTING.md) 与 [发布标准](RELEASE.md)。
