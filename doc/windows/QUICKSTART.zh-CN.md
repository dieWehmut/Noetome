# Noetome Windows 11 x64 实测指南

本包用于「自己的 PDF → 模型候选 → Obsidian 待核验笔记」首次实测。安装包包含桌面程序、CLI、锁定的 PDF Python 环境、运行库、模型辅助程序和离线作者样例，无需另装 Rust、Node 或 Python。Noetome 当前版本为 0.1.0；本次构建的源提交、文件摘要和实际体积见随包 delivery.json 与 SHA256SUMS.txt。

## 安装和离线检查

1. 将安装包和 SHA256SUMS.txt 下载到本机。可以在 PowerShell 执行 `Get-FileHash -Algorithm SHA256 -LiteralPath '安装包完整路径'`，与随包摘要比对。
2. 双击 `Noetome-0.1.0-B15-…-windows11-x64-setup.exe`，按安装向导操作。默认安装到当前用户目录，开始菜单中的 Noetome 快捷方式启动桌面。本测试包没有 Noetome 代码签名证书；若 Windows 显示发布者未知，请先核对来源和摘要，再按本机允许的安装方式操作。
3. 在首页的「离线安装自检」点击「运行离线样例」。结果应给出新的测试输出目录和 Vault 路径。它使用作者写好的 fixture，模型调用和网络请求均为 0，只验证安装与本地编译链。

安装目录的 `samples/single-page.pdf` 为可提取文字的作者 PDF，`samples/scanned-page.pdf` 为扫描状态样例；二者不代表真实模型抽取质量。`payload-manifest.json` 记录随程序安装的各个资源摘要，`runtime-receipt.json` 记录 PDF 环境来源与版本。

## 用自己的 PDF

1. 在项目入口选择父目录，并输入新的项目名称。首次建议在专用测试文件夹建立项目，例如 `D:\Noetome 实测\我的教材测试`。
2. 进入资料页，明确选择自己的单份 PDF 并导入。等待检查结果，查看物理页定位与可用原文区域。MD/TXT 也可以用于验证相同流程。
3. 选择本次要整理的非空原文。一次最多 64 个单位，总正文最多 64 KiB；从一页或一个小节开始更方便核对。批量选择也受相同限制。
4. 点击原文预览，核对将发送的完整正文，再确认生成模型候选。切页会保留当前项目；生成中可取消，结果恢复入口可读取已保存的成功 API 目录。

扫描、空白、加密、损坏或布局需复核的资料会显示对应状态。当前包没有通用 OCR；没有可确认正文的区域不能进入模型候选生成。请先用有文字层的 PDF 完成首次实测。

## 模型设置和预算

打开设置中的模型入口，查看当前服务、凭据和用量状态。本轮接入既有糖猫兼容 API 与 deepseek-flash；实际生成需要联网和有效服务密钥。点击保存凭据会打开 Windows 遮蔽输入窗口，密钥按当前 Windows 用户加密保存，网页界面不接收明文。

已有有效凭据和账本会复用。若账本缺失，界面默认不恢复；只有确认旧的十次历史之后，才能恢复完整历史记录。基线为累计 33,185 已用、0 待结算、9,966,815 剩余，历史不会被清零。若已有后续调用，请保留当前账本，不用基线覆盖。损坏或未知用量需要先检查，界面不会自动追加请求或重试。

原文确认表示允许将本次选定正文发送到当前服务。模型返回的候选仍需人工核对；模型耗时、失败和预算预留会显示实际状态。恢复已有成功结果和再次导出不产生额外模型调用。

## 在 Obsidian 查看

1. 候选成功后，选择专用测试父目录，输入尚不存在的新输出目录名称。程序会创建一个包含 `vault/` 和 `reports/` 的新根。
2. 在 Obsidian 中选择「打开文件夹作为仓库」，打开新根中的 `vault` 文件夹。
3. 从「待核验笔记」总览进入概念和证据笔记，核对解释、原文引用、条件、单位与物理页定位。附件保存原始 PDF；PDF 页码按物理页记录。
4. `reports/` 保存请求、原始响应和候选校验信息，便于反馈错误。分享前自行检查其中是否包含不想分享的资料正文。

这些笔记明确标记待核验、尚未发布。首次实测请使用新的测试 Vault；程序拒绝现存导出目录和已存在的 Obsidian Vault 祖先目录，避免覆盖人工内容。不要选择正在使用的生产 Vault 作为导出目标。

## 卸载和反馈

在 Windows「设置 → 应用 → 已安装的应用」中卸载 Noetome。安装资源被移除；你选择的新项目和导出目录由你保留。反馈时提供构建源提交、发生步骤、资料状态、错误码和经过检查的日志，勿提供 API 密钥。

本次安装和作者样例测试不证明真实外部模型的科学正确率、通用 OCR、整本大型教材整理或生产发布已经验收。请从少量自己的 PDF 内容开始，逐条核对模型候选与原始证据。
