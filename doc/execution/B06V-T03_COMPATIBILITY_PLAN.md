# B06V-T03 视觉输出跨版本实际兼容方案

本项按用户“持续进行本项目开发”授权推进；唯一活动任务和历史以任务账本为准。计划不能作为实际兼容验收，执行结果记录于 `doc/validation/B06V-T03.md`。

## 版本与原件边界

执行时读取官方 Obsidian GitHub release、稳定更新频道和官方 changelog 原字节，冻结实际稳定版 **1.15.0**；beta 1.15.1 不进入本矩阵。最低产品支持基线是已有实际验收的 **1.6.7**，上游更新频道的 `minimumVersion` 不代替 Noetome 最低支持承诺。

1.15.0 官方 Windows 安装器只在新的 `.artifacts` 目录解包，安装器、更新 ASAR、解包成员和实际包版本逐字节核对。旧日常安装只读核对，不安装覆盖、不注册协议、不写生产 Vault。每次显示均使用明确的新 Vault、profile、PID 和 CDP 端口；失败只清理经命令行确认归属本次 profile 的进程。

最低版的 MathJax 核心为3.2.2、Mermaid为10.6.1。1.15.0 安装包已改变 MathJax 文件路径；静态检索曾读到5.0.0与4.1.2字符串，但它们不能识别实际引擎。隔离应用探测实际 `window.MathJax.version` 为 **4.1.3**，并以CDP执行脚本SHA与安装成员原字节相等绑定。新流程实际加载 `lib/pele.min.js`，执行脚本头声明 **Pele 1.8.0**，应用通过兼容接口处理 Mermaid 代码块；实际未暴露Mermaid版本，记录null，不虚构版本。运行时探测只确定身份，完整语义显示仍须分别验收。

## 独立冻结与实际显示

在 `fixtures/visual-compatibility/` 冻结12份真实已有产品产物及作者预期：比较表特殊中文标签与详情链接；分支流程与保留LF/Tab的文字回退；负号/分式/脚标、关系方向及原区域回退；正负箭头SVG与无数据曲线PNG；扫描清晰重建、原区回退及两处关键缺损阻断。原件从既有受审计归档读取，保留来源、命令、SHA和独立作者语义，不改原响应或预算锚。

另冻结一份明确标为手写的阅读格式探针，覆盖Properties字符串/布尔/列表、Callout、中文H2标题、标题Wikilink与合法块ID/块链接。它只证明两版干净阅读器对这些格式的实际支持，不冒充产品已实现这些输出生成能力。新的独立流程补充包冻结既有复杂标点及促进/抑制关系输出，补足当前引擎能力批准前的标签转义与正负关系实测；原13案冻结包保持原字节。

两版本分别浅/深主题实测，每场新Vault/profile。原生采集必须核对实际app/userData/Vault/空社区插件、全部源字节、数学树及可见几何、流程标签/分支/方向、SVG原生解码与同实例辅助几何联结、PNG自然尺寸和实际点击后的本地image视图。表格/流程链接实际点击后核对目标文件和标题；格式探针另核对可见Properties、Callout与标题/块定位。无成功表达的扫描产物不得出现成功计划或预览。

采集器从本项独立运行时记录读取预期，不从待验收产品profile推导实际版本。执行脚本来源必须与选定安装成员原字节绑定；MathJax实际window版本独立核对。保留旧采集器、失败原DOM/截图/命令；新DOM若改变，只做有据适配，不删除关键语义判据。

## 编译器能力与收束

先对冻结已有输出进行实际跨版本渲染验证，再按结果加入精确能力组合。公式与扫描共享实测MathJax判据，流程与SVG各自保留独立能力条件；未知版本、混配引擎、无依据的`verified=true`均不能升级为原生成功。若新流程引擎没有可知语义版本，可用实际锁定的安装与脚本身份记录证据，不能把未知伪装成Mermaid版本；接口如需改变，保留旧Schema并另行冻结严格新profile。

独立Python语义核对不导入Rust渲染或能力判断；同步伪造目标版本、运行时记录、矩阵通过声明及原响应/正文/报告指纹，仍必须拒绝换符号、丢前提、关键未知假成功和虚假原生表示。新能力对应普通CLI回归及实际显示证据逐项联结；扫描本轮无需新增收费请求，人工环回测试与既有真实识别原件分开记录。

源码稳定后执行完整Rust/Python和全部既有视觉审计、独立审查、日志与Git检查。矩阵仅写入真正通过的显示组合；未运行平台、科学质量、通用扫描和生产发布不扩大声明。完成本项后依据PRD剩余需求及真实结果评估B07进入条件，滚动展开最多三项任务，再按连续授权顺序推进，每项独立验收和提交。
