## B04-T01 Python解析侧车协议

依赖：B03-T04

关联：FR-02、FR-36、NFR-14、NFR-15

**先读规范**

- [doc/technical/RUNTIME_PROTOCOL.md](../../../doc/technical/RUNTIME_PROTOCOL.md)
- [doc/technical/STACK.md](../../../doc/technical/STACK.md)

**实现步骤**

1. 建立uv项目和锁文件；实现版本化stdin/stdout协议，stderr日志，限制frame与资源大小。
2. Rust子进程适配器仅传授权源路径/输出根；校验返回路径、hash和request_id。
3. 用stub覆盖超时、超大响应、stderr噪声、退出中断和恶意相对路径。

**必须交付的文件**

- sidecar/parser/pyproject.toml
- sidecar/parser/uv.lock
- sidecar/parser/src/noetome_parser/__main__.py
- sidecar/parser/tests/test_protocol.py

**验收结果**

- JSON协议与日志分离；取消能回收子进程；Core不信任sidecar成功标记。

**本任务边界**

- 先stub协议，不声称解析PDF。

**失败处理**

- 先保留最小复现与实际错误；同一根因最多连续修复3轮，每轮只改变一个可检验假设。
- 若仍失败，按 FAILURE_PLAYBOOK 分类记录阻塞与解除条件；不能删除失败用例、降低门槛或将未运行结果记为通过。

## B04-T03 扫描PDF OCR与不确定区域

依赖：B04-T02

关联：FR-03、FR-24、AC-16、NFR-06

**先读规范**

- [doc/technical/KNOWLEDGE_PIPELINE.md](../../../doc/technical/KNOWLEDGE_PIPELINE.md)
- [doc/technical/STACK.md](../../../doc/technical/STACK.md)

**实现步骤**

1. 按配置dpi渲染扫描页并调用Tesseract中文/英文，记录原图和OCR token bbox。
2. 按阈值标记低置信/公式疑似区域，保留原区域供核验。
3. 加入倾斜扫描、混排、负号/下标模糊、空白页和缺少语言包用例。

**必须交付的文件**

- sidecar/parser/src/noetome_parser/ocr.py
- sidecar/parser/tests/test_ocr.py

**验收结果**

- 原图永不丢失；低置信字符不能自动宣告语义已核验。
- 无OCR依赖或语言包输出明确blocked_capability，非成功空解析。

**本任务边界**

- 通用OCR不是公式识别权威；不承诺原始TeX逐字恢复。
