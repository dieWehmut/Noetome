## B11-T02 Windows并发编辑保护与应用

依赖：B11-T01

关联：FR-30、FR-32、FR-33、FR-34、AC-21、AC-22、AC-27、AC-37、NFR-07、NFR-08

**先读规范**

- [doc/technical/PUBLICATION.md](../../../doc/technical/PUBLICATION.md)
- [doc/technical/RUNTIME_PROTOCOL.md](../../../doc/technical/RUNTIME_PROTOCOL.md)

**实现步骤**

1. 按排序获取Windows文件保护句柄，拒绝共享写/删除，重读hash后应用。
2. 文件占用或新建冲突转blocked，无权限降级路径；每步持久journal。
3. 独立进程在审批后、CAS后、replace附近改文件，验证无未批准覆盖。
4. Core只保留状态机；实际Win32句柄与no-replace安装放adapters，使用真实NTFS文件和外部进程竞争测试，禁止fake端口替代。

**必须交付的文件**

- crates/noetome-core/src/publish_apply.rs
- crates/noetome-core/tests/publish_apply.rs
- crates/noetome-adapters/src/windows_publication.rs
- crates/noetome-adapters/tests/windows_publication.rs

**验收结果**

- 竞争修改在文件锁/CAS路径被拒绝或导致阻断；非托管内容零变化。
- 任一步失败不报Release成功。

**本任务边界**

- 没有不锁文件的兼容回退；不支持目标文件系统则明确拒绝。

**失败处理**
