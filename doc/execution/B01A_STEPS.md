## B01A-T01 桌面关闭托盘和可保存的退出设置

**单一结果**：安装后的Windows应用按用户选择处理 ×，默认隐藏到托盘；普通最小化保留任务栏窗口，托盘能恢复原窗口并明确退出。

**依赖**：B01-T03。关联依据：用户2026年11月1日要求托盘，随后明确确认“× 默认隐藏；托盘菜单退出程序”，并要求最小化按钮后任务栏仍有窗口。关闭方式可设置为直接退出。这是桌面交付行为，不代表项目业务、持久后台任务或完整桌面产品验收。

### 执行步骤

1. 核对当前Tauri版本的托盘与关闭事件API，复用指定图标。由Rust管理托盘与关闭方式，不开放新的任意文件、进程或shell前端入口。
2. 取消最小化时隐藏窗口的行为，保持普通Windows最小化及任务栏窗口。× 默认隐藏到托盘，保留进程与页面状态；选择直接退出时 × 结束程序。托盘左键恢复主窗口，右键菜单提供“显示窗口”和始终结束程序的“退出”。
3. 关于页增加“窗口行为”设置区，读取实际关闭方式，允许保存“隐藏到托盘 / 直接退出”，重启后保持选择。查询、失败后重试以及 × 决策前实际重读受限文件，避免旧缓存持续生效。设置采用版本化受限配置，读取和保存失败有稳定错误；写入失败不得改变当前行为或把未保存值显示为成功，未知内容不能被覆盖。
4. 恢复时取消最小化、显示并聚焦已有主窗口，不重建页面。创建托盘失败须明确报告，不能把隐藏窗口留成不可恢复状态。
5. 验证设置默认值、合法保存/重读、非法值、损坏或不支持版本、占用/保存失败及原内容保护；运行相关格式、工作区与前端检查，重新构建NSIS并在正常用户目录准备、安装当前包。
6. 在实际安装后的窗口验证默认 × 隐藏/进程存活、普通最小化保留任务栏、左键及菜单恢复、导航/输出保留、直接退出设置及重启持久化、改回隐藏设置、托盘退出、快捷方式重启及Rust通信；检查设置的键盘操作与失败提示，保存包和安装文件指纹。
7. 同步[设计](../standards/DESIGN.md)、README及独立验证记录，用日志工具完成，分步提交，检查通过后推送并核对远端。

### 验收

- 使用既有图标，托盘图标与Noetome提示出现。
- 未配置时 × 隐藏窗口、进程存活；最小化按钮保留任务栏窗口，能从任务栏恢复。
- 托盘点击和“显示窗口”菜单均恢复窗口/焦点与已有导航、运行输出。
- “关闭窗口时”保存隐藏到托盘或直接退出，实际 × 行为符合所选值，重启后保持；加载/保存失败不报告假成功、不改原已保存值和当前行为。
- 托盘“退出”始终结束进程并移除图标，不受设置影响；快捷方式能重启。
- 当前构建与安装文件严格匹配，既有帮助/版本及相关回归通过。

```powershell
cargo fmt --all --check
./scripts/cargo_local.ps1 check --workspace --locked --offline
./scripts/cargo_local.ps1 test --workspace --locked --offline
npm run web:build
npm run desktop:build -- --ci -- --locked
./scripts/install_desktop.ps1
python -m unittest discover -s tests -p 'test_*.py'
python scripts/devlog.py check
git diff --check
```

构建和代码检查不能代替原生托盘实测。仅验收当前Windows环境；本项不接项目GUI、不增加开机启动、驻留任务或模型功能。
