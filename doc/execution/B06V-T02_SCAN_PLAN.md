# B06V-T02 明确扫描公式实施方案

本项只推进[扫描公式任务](B06V_STEPS.md)，实际状态由[账本](../../dev-log/tasks.json)维护。本文记录实施边界和待执行验收，不能作为已运行识别或测试的证据。

## 一个明确来源与一个识别方案

独立作者先制作公开自造、CC0 的单页扫描样例：有界标量分式及真实页上符号定义、单位、前提、范围和例外。清晰页、负号缺损页和下标缺损页是同一个作者用例的三个扫描状态；不是三份真实文献或科学准确率分母。原页 PNG、确切裁剪区域、归档 PDF 和独立 expected 必须先冻结，再取得普通 CLI RED，最后才运行识别。修改原件或预期须先说明理由，保留旧版本和失败。

选用本地 pix2tex 0.1.4，锁定安装依赖、模型配置与权重 SHA，以及本项目单请求 adapter 的源码/payload。安装时允许下载公开依赖和权重；普通 CLI 不下载、不联网、不自动重试。真实运行需使用明确指定且已核对的独立 Python 环境和模型目录。版本清单、安装成功和权重存在都不能代替真实识别。

当前 DeepSeek 官方资料已声明 `deepseek-flash` 支持图像，见[能力页](https://api-docs.deepseek.com/quick_start/pricing)与[视觉协议](https://api-docs.deepseek.com/guides/vision)。这不证明用户网关实际视觉路由或底层版本。本项选择固定本地方案，不调用模型服务；现有凭据、累计预算和历史响应保持原记录。

## CLI 与来源边界

```text
noetome knowledge scan-formula <scan-case目录> <profile.json> <尚不存在的新测试Vault>
```

scan case 使用独立 Schema1，明确 selection、整页 PNG、页号/画布、区域 PNG 与矩形、可辨性、手工来源语义及可选归档 PDF。清单严格且所有附件为普通直接子文件，拒绝未知字段、重复键、链接、硬链接、越界、碰撞、身份及字节变化。

定位以实际整页 PNG 像素坐标为依据，区域 PNG 必须逐解码像素等于该页矩形。可选 PDF 保存原始字节；本入口不把调用者的页号和 PNG 声明当成通用 PDF 页面解析验证。独立作者审计另行检查本用例归档 PDF 与原页的一致性，并明确此层证据的范围。

识别请求只包含请求身份、选定区域及实际指纹、显式模型目录和有界运行策略。作者语义声明、独立 expected 及生成样例时使用的源码不得进入识别输入。来源声明中的表达是手工语义转写，不能称为识别结果或作者原始 TeX。

## 识别、核对与表达

单请求 adapter 返回未经手工修补的识别文本及原始响应，记录实际 producer、版本、模型指纹和运行范围。普通 CLI 使用现有 Windows 进程树宿主的时间、管道及进程退出保护，不把 Job Object 称为文件或网络沙盒。Linux adapter 实跑和 Windows 普通 CLI 验收分开记账；不从一方结果推定另一方宿主支持。

Core 在识别返回后才按既有有界数学语法核对手工来源语义，保留负号、变量、分子/分母、上下标和关系方向。只允许明确检查的等价规范化，例如单操作数脚标的括号形式；记录每项改写，不用外观相似或模型自信通过。

清晰且语义一致时才选择已验收 Obsidian 1.6.7 / MathJax 3.2.2 的重建表达，或在目标能力不足时使用原区域图片。来源关键符号不可辨、语义未知或识别不一致时阻断受影响表达；即使识别器猜出清晰页答案，也不能把缺损页洗成成功。

新测试 Vault 保存原件、来源声明、profile、实际请求/原响应/诊断和 JSON/Markdown 双报告。成功另存识别表达、等价编译表达、计划和预览；阻断保留原区域及问题，不留下成功计划或编译预览。输出保持知识 pending、科学验证 not_run、published=false。

## 必须实际执行的验收

1. 识别前冻结作者原件/expected，普通 CLI RED；实际清晰与缺损识别响应和来源指纹。
2. 普通 CLI 到全新 Vault，重建、目标原图回退和关键未知阻断；原输入与运行时守卫、资源限额、祖先、碰撞、哨兵及未知人工现场保护。
3. 独立语义/实际正文与字段映射检查；同步篡改符号、前提、区域、计划、双报告和指纹仍拒绝假成功。
4. 干净 Obsidian 的真实数学渲染、原区域和附件对照；完整 Rust/Python 与既有表格、流程、公式、图像回归，独立审查并修复实际问题。

每项保留环境、命令、退出码、数量、原件和失败历史。只有这些实际证据完成后才 complete、提交和推送；本项不启动视觉兼容矩阵，不推定一般扫描 PDF、多栏、任意公式或科学正确率通过。
