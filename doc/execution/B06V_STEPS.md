# B06V 剩余视觉目标

B06 比较表、过程流程与明确公式源码/原图回退分别按实际证据验收；这些有界工程能力不代表整个视觉阶段完成。B06-T03 的结果见[验证记录](../validation/B06-T03.md)。本批只细化下面三项，真实状态仍由任务账本维护；规划和切批次不启动实现。

## B06V-T01 一般来源图像的有据重现与重绘回退

**单一可见结果**：明确选定的来源图像保留关键标签、箭头、单位、图例和空间关系；可核对的图示才允许重绘，缺原始数据的实验曲线保留原图。

依赖 B06-T03，关联 FR-22、FR-23、FR-25、FR-26、NFR-06。先限定公开自造、明确选定的少量本地图像及作者独立元素/关系预期，覆盖带标签方向图、关键空间关系和无数据曲线。使用真实原件身份与严格版本化图像表达契约，不把手工结构声明称为一般图像自动理解，不扫描私人目录、不引入完整知识图谱或 OCR 系统。

先冻结原图、关键元素及独立 expected，取得普通 CLI RED；再实现明确原图重现、确有依据的有限重绘和原图/阻断决策。独立校验来源映射、标签/箭头方向与正负、单位/图例/空间关系；同步改图、计划、两报告和指纹仍拒绝语义遗漏。无原始数据曲线不能生成虚构精确数据；原图可用则保留，可辨性不足仍阻断受影响表达。

完成门槛是普通 CLI 到新 Vault、实际图像/相对附件、篡改与祖先/碰撞/哨兵保护、完整 Rust/Python、表格/流程/公式回归、记录版本的干净 Obsidian 实测和独立审查。通过后 complete、提交推送；下一项为明确扫描页公式，不能由本项声称任意来源图像科学理解已完成。

## B06V-T02 单个明确扫描页公式的重建与语义复核

**单一可见结果**：选定扫描页/公式区域可以尝试重建等价表达，原区域保留，不能分清的关键符号或负号明确阻断。

依赖 B06V-T01，关联 FR-03、FR-24、FR-25、FR-26、NFR-06。只选择一个实际解析/识别方案并锁定版本，限定公开授权扫描样例、明确页与区域；不实现通用 OCR 系统或扫描整库，不承诺恢复作者原始 TeX。若使用已授权文本/视觉服务，先核对服务真实能力、凭据复用与累计预算；授权边界外的收费能力不能默默启用。

原始扫描页、独立作者符号/前提和表达 expected 在识别前冻结，取得真实 CLI RED。保存识别原响应/置信问题及等价 TeX、关键语义核对和原区域映射。至少包含可辨公式和负号/下标/关键符号不可辨输入；实际识别成功不替代独立语义核对。同步假成功、误换符号、丢前提、区域替换/越界都须拒绝。

实际 CLI 到新 Vault、原区域与重建表达的 Obsidian 对照、完整回归、资源保护和独立审查通过后完成。本项的样例数量和未识别范围如实记录，不能推定一般扫描 PDF、多栏或科学正确率通过。

## B06V-T03 视觉输出的最低与当前稳定版兼容矩阵

**单一可见结果**：已实现表格、流程、公式、原图及扫描回退在选定最低支持版与实际当前稳定 Obsidian 中可用，未支持组合有明确回退。

依赖 B06V-T01、B06V-T02，关联 FR-25、NFR-06、NFR-16 和 D13。执行时从官方来源核验当前稳定版，明确最低支持版及对应内置 MathJax/Mermaid 运行时，保存下载/版本指纹；不把旧辅助字符串或 profile 自报作为版本证据，不覆盖用户日常安装/生产 Vault。

冻结跨版本代表性输出与独立语义预期，在各自干净独立配置中实测表格、中文路径和链接、Mermaid 方向/标签/回退、MathJax 语义、本地图像/附件及扫描阻断。仅经真实验收的组合可加入编译器能力记录；未知版本维持未经验证或已核对回退。同步伪造兼容声明不能放宽语义门槛。

完整 Rust/Python、全部既有视觉回归及独立审查通过后保存可重复矩阵、原件和未运行项，complete 并推送。然后按剩余需求和真实结果判断 B07 进入条件；兼容矩阵不代替正式科学质量基准或生产 Vault 人工保护。
