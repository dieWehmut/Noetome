# B13 执行步骤：规模与长时实测

本批次只做一件事：把 NFR-09 至 NFR-12 从"未测"变成"有原始日志的实测结论"。
所有输入都是合成数据，**不证明真实教材抽取质量**，也不冒充真实 PDF 规模。

## B13-T01 合成规模输入与千页万原子规划的实测口径

- 单一可见结果：一份可复现的规模报告，写明参数、耗时、峰值内存与产物摘要。
- 依赖：B12-T03。
- 顺序：生成器 → 千页/万原子/千笔记三档 → 两次运行字节比对 → 审计器。
- 验收：规模可参数化；未达门槛如实写；两次产物相同；审计器复算。
- 停止：真实 PDF 抽取质量不在本卡范围；不做模型调用。

## B13-T02 大库增量与人工改动的规模实测

- 单一可见结果：3000 笔记、200 处人工改动下的变更规划耗时与内存，逐阶段给出。
- 依赖：B13-T01。
- 顺序：合成大库 → 变更规划 → P95（样本量、warmup、是否含进程启动全部写明）→ 审计器。
- 验收：分阶段数字；P95 口径完整；原始日志入库；审计器复算。
- 停止：不优化算法，只测量并如实报告。

## B13-T03 长时运行与暂停语义的可复现 soak

- 单一可见结果：一段可复现的 soak 日志，含轮次、耗时、内存、错误码与暂停窗口。
- 依赖：B13-T02。
- 顺序：soak 脚手架 → 指定时长运行 → 暂停 2 秒语义验证 → 审计器。
- 验收：崩溃留命令；暂停后可观测计数停止增长；未满 24 小时必须写「未达到 NFR-09」。
- 停止：不宣称长时稳定性已达标。
