# 自动测试与最少人工介入

用户只需对接手Agent说 **“继续这个项目”**。这句话表示按全V1计划持续推进，不是只做一个任务。Agent负责读状态、实现、运行测试、修复、记录、commit/push和继续下一项；不用让用户手工敲命令或读代码找错误。

## 当前已经可用的入口

```text
python scripts/autotest.py
python scripts/autotest.py --task B01-T01
```

无参数检查当前仓库的日志/计划/文档/SQL/工具测试；不声称产品已经实现。带task先跑通用检查，再实际执行该任务定义的产品检查、生成绑定源码的verify报告。产品尚未实现时带task失败是正确行为，不能增加跳过开关。

开发时由Agent调用，不要求用户操作。详细结果在`.artifacts/autotest/latest.json`，任务验证报告在`.artifacts/verification/<ID>.json`。日志complete复查报告，后续源码变化须重验。

## 产品自动测试如何实现

| 层次 | 实现任务 | 自动化要求 | 不能替代的结论 |
| --- | --- | --- | --- |
| CLI/输入/Schema | B01、B02 | 临时目录、真实子进程、失败退出码、迁移前后比对、非法引用负例 | 真实资料知识质量 |
| 完整编译 | B03、B06至B09 | 固定来源/IR/gold、字节对账、跨层映射、链接、必要原子、条件与单位 | 模型同轮自评不能当独立gold |
| PDF/OCR | B04 | 自有小PDF/扫描/旋转/损坏/缺页样本，bbox与原区域对照 | OCR置信分不代表事实正确 |
| 外调与预算 | B02、B05、B12 | 本地HTTP stub模拟429/超时/畸形输出/未知费用/恶意网页，默认不收费 | 真实端点及研究质量 |
| 文件安全 | B10、B11 | 外部进程并发编辑、逐步killpoint、磁盘/占用故障、恢复和回滚哨兵 | 不能只测内部函数或假文件系统 |
| 桌面 | B14、B15 | Vitest组件+真实Windows WebDriver E2E，稳定testid，失败截图，自动回收进程 | mock IPC不等于真实Core/worker交互 |
| 安装 | B16 | 干净环境真实安装产物、断网运行、升级卸载、数据保留 | 开发目录能启动不代表安装成功 |
| 容量/长任务 | B17 | 脚本运行规定规模、24h实际工作时间、睡眠/崩溃恢复与资源曲线 | 缩小样例或模拟时钟不能算通过 |
| 正式交付 | B18 | 读取真实证据验证阈值、版本、指纹、完整需求关联 | 用户体验和知识审阅不能伪造 |

具体框架与Windows自动化细节见[UI自动化](../technical/UI_AUTOMATION.md)，测试规则见[TESTING](../standards/TESTING.md)，正式证据字段见[RELEASE](../standards/RELEASE.md)。所有小任务都带确切命令和测试文件路径，不要求执行者重新设计测试体系。

测试必须能在新临时目录运行，不触碰用户生产Vault。使用固定seed、固定fixture版本、实际运行环境、明确时区；失败报告包含输入manifest、最小复现命令和观察结果，不包含密钥和私人教材正文。

## 用户只在这些位置参与

1. **真实服务配置**：若尚缺API/检索凭据、预算和授权资料，由Agent说明需要的最小输入。只需配置一次，不在每次请求前重复询问。前期离线开发继续。
2. **知识样本确认**：在正式质量门禁中，由Agent展示短样本、关键图公式及判定标准，用户或具备相应知识的人确认gold/争议。普通技术测试无需人验；已有合法独立gold与审阅证据可复用。
3. **最终体验**：所有可自动完成的门禁先通过，Agent展示可运行安装产物和可读样例，用户确认“导入、找到知识、追溯/审批”体验。没有用户实际结论不能自填验收通过。

其他用户请求仅限真正无法自治消除的外部障碍。测试失败优先自动修复；同一根因3轮仍失败，提交清楚的[阻塞报告](FAILURE_PLAYBOOK.md)，不是请小白自行调试。用户随时可以主动要求阶段展示，但不作为每个小任务的必需审批。

## 自动推进的实际边界

Agent会在当前活动会话和工具可用时持续推进。终端任务、持久Job和日志支持重新接手；模型上下文结束、应用关闭或服务额度耗尽时，仓库文件本身无法唤醒一个未运行的Agent。再次说“继续这个项目”会从账本恢复，不需要重新解释项目。这里不偷偷创建定时任务或收费后台服务。

已测试的旧候选发生产品代码变化时，必须重新执行受影响真实测试，不能只刷新证据时间。单纯保存报告或新增不进入产品构建的harness不使全部产品结果自动过期，具体指纹边界见RELEASE。
