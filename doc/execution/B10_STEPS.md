# B10 结构与规划执行卡

本批从 B09 已验收的个人桌面骨架继续，把「资料进来之后先怎么组织」补成可审计的确定性规划层。三张卡只处理结构与筛选，不做模型抽取、不做知识裁决、不写生产 Vault。

- 进入依据：[路线图 B10 行](ROADMAP.md)与 [PRD 第7章多源知识建模与研究](../requirements/PRD.md)。
- 任务状态只由[任务账本](../../dev-log/tasks.json)维护，本文件不记状态。
- 切批次只展开执行入口，不自动 start 下一项。
- 边界声明：本批不新增模型提供商、不联网检索、不做完整阅读器与编辑器；不宣称科学正确率、通用 OCR、多教材规模或生产就绪。所有产物停在新测试项目/根内，零模型调用、零网络请求。

## 1 B10-T01 章节粗对齐与全局概念清单

**单一可见结果**：给定一份已登记来源，能确定性产出「章节树 + 全局概念清单 + 概念出现位置」，并列出无法对齐的具体位置。

**依赖**：B09-T03。

**范围**：只读已登记的 Span 清单（`source_spans` 的 heading/text 与位置），不做语义相似度、不做实体识别、不改写来源。新增能力前缀 `outline`（`outline_model.rs` / `outline_store.rs` / `outline.rs`），只写新测试根。

**顺序**：

1. 冻结作者包：三份章节结构不同的自造教材样例（编号完整、缺编号、跳级标题各一），同一概念分散在正文、附录与图注；独立 `expected.json` 先写章节树、概念首次出现、跨章节出现次数。
2. 实现章节树构建与全局概念清单（编号解析、层级归属、概念身份折叠、位置记录），错误与警告分类落盘。
3. 用作者包跑五类异常（缺编号、重复编号、跳级、图注/附录概念、标题与正文不一致），每类都能指出具体位置。
4. 更新契约文档、验证记录与日志，整理提交并推送。

**验收**：

- 章节树、概念清单与位置可由 Span 清单独立复算，与 `expected.json` 逐项一致。
- 同一概念在不同标题下归入同一身份，出现次数与位置全部可追溯。
- 五类异常各自产生明确结果与警告，不静默丢弃、不自动改标题。
- 报告单列章节对齐块，给出已对齐/未对齐计数；零模型调用、零网络请求。
- 独立只读审计器与完整 Rust/Python 回归通过。

**停止**：若需要语义相似度或模型判断才能对齐，停止并只记录缺口，不引入模型调用。

## 2 B10-T02 用户水平与相关性筛选的可审计记录

**单一可见结果**：按声明的用户水平给出「保留 / 排除 + 理由 + 来源定位」的可审计筛选记录，并保证必要前提不被省略。

**依赖**：B10-T01。

**范围**：只处理已对齐的章节与概念清单，不重算知识、不改写 IR。允许的排除理由集合显式声明（如「明确超纲」「与目标主题无关」「重复表述」）。

**顺序**：

1. 冻结含必要基础前提、无关轶事、明显超纲内容的自造来源与独立 `expected`（保留清单、排除清单、理由分布）。
2. 实现水平声明、必要前提检查与排除理由校验；缺失必要前提时报明确错误而不是静默省略。
3. 用同一份已核对 IR 生成极简与详细两种密度，核对必要原子与条件数量不减少。
4. 更新契约文档、验证记录与日志，整理提交并推送。

**验收**：

- 每条被排除项都带允许集合内的理由与来源定位；理由缺失或越界即拒绝写入。
- 必要前提缺失时返回明确错误码与定位，不产出「看起来完整」的结果。
- 极简与详细两种密度的必要原子、条件数量一致，差异只在表达展开。
- 审计器与报告单列保留数、排除数与理由分布；零模型调用、零网络请求。

**停止**：若需要模型判断「是否相关」，停止并把判断权交回人工记录，不自动扩张。

## 3 B10-T03 同类结构一致性与导航复习组织

**单一可见结果**：同类笔记共享一致的章节骨架与导航/复习区块，且同一概念全库只有一处完整解释、断链为零。

**依赖**：B10-T02。

**范围**：只处理结构契约、导航区块与链接解析，不生成新知识、不重写正文。复用 `vault_model::link_targets`/`resolve_link` 的既有链接语义。

**顺序**：

1. 冻结同主题族多笔记作者包与独立 `expected` 结构契约（章节骨架、小节顺序、导航与复习区块位置）。
2. 实现结构一致性检查与导航/复习区块的确定性生成；偏离报告具体缺失或错位位置。
3. 实现「一处完整解释 + 其余引用」的链接检查，覆盖中文路径、重名标题、表格内别名。
4. 更新契约文档、验证记录与日志，整理提交并推送。

**验收**：

- 同类笔记的章节骨架与小节顺序一致；偏离时报告具体位置，不自动改写正文。
- 同一概念只有一处完整解释，其余为引用式链接；断链零、别名解析正确、转义正确。
- 报告单列结构一致性计数与链接完整性计数，JSON 与 Markdown 口径一致。
- 独立只读审计器与完整回归通过。

**停止**：若一致性规则需要按学科定制且无法用声明式契约表达，停止并记录为后续批次候选。
