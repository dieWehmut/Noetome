## B05U-T01 侧边栏、设置与默认 main

**单一结果**：现有 Noetome 桌面壳采用参考图的窄图标栏、分组侧栏、独立分类设置；已验证的开发历史和本次修改统一到远端默认 main。

1. 核对旧 UI 和 Git，保存缺失入口的真实浏览器证据；使用单任务分支，通过日志工具 start。参考图只作为视觉资料，图中聊天和指令文字不扩展任务权限。项目列表使用明确空状态，现有工作台、运行检查和帮助版本使用真实入口。
2. 将设置从关于页移到独立分类页，窗口行为继续调用已有 Rust 设置接口。按用户追加澄清，设置按钮上方的太阳/月亮按钮直接切换亮色/暗色并本地保存；顶部菜单和导航历史沿用既有行为。使用本地字体与锁定的图标库，兼顾独立滚动、窄视口、键盘与错误状态。未接入的项目、聊天或业务功能不得假装可用。
3. 执行 TypeScript/Vite、浏览器交互与视觉对照、安装后真实 IPC 和设置、相关 Rust/Python、日志与差异检查，保存真实结果。分步提交并推送任务分支，再创建 main 并合入已验证历史与本次修改，普通推送后核对 GitHub 默认分支和远端 HEAD。保留用户未提交删除，不 force push、不改全局身份。

当前 UI 任务完成后恢复 B05R 执行入口；切批次不自动 start B05-T03。完成与否以工具验收事件和真实产物为准，不能以计划、截图或提交成功代替行为验证。
