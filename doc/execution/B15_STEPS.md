# B15：Windows 上手实测交付

用户在 2026-11-09 要求补齐当前缺口并提供 Windows 安装实测。当前最直接的阻断是桌面未接来源导入与运行启动、安装包未包含 CLI/PDF 环境，以及既有失败记录缺少锁定环境下的最新原生回归。

按顺序执行三个任务，每次仅一个 `in_progress`，状态以 [账本](../../dev-log/tasks.json) 为准：

1. **B15-T01**：建立 Windows 原生检查工作流，精确准备 Rust/Node/可搬移 CPython 与 PDF 依赖；实际重跑回归，修复可复现失败并保存原始结果。Linux 上的 Windows 进程树拒绝不擅自改成支持。
2. **B15-T02**：新建/打开项目的状态在切页后保留，选择父目录与新项目名；接入用户显式选取的单份资料导入与检查；接入明确标记的离线样例及既有检查点控制，在新测试根提供可读 Vault 和报告。
3. **B15-T03**：制作包含 CLI、锁定 PDF 运行环境、离线样例和中文说明的 NSIS；安装后核对实际 payload、来源解析、样例输出、快捷方式与卸载，再交付下载产物和指纹。

原生安装 smoke 与人工窗口交互分开记录。样例不证明真实模型抽取、科学正确率或完整教材编译；仍未通过的正式规模/科学/生产 Vault 门槛如实保留，不用功能任务的 `done` 替代。
