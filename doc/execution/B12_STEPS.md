# B12 教材式自适应规划执行卡

本批承接 B11 已验收的迁移与追溯层，补 PRD 里最后一个尚未落地的一级功能需求：
教材式自适应规划。三张卡只做确定性规划与规划变更，不做模型抽取、不做知识裁决、
不写生产 Vault。

- 进入依据：[路线图 B12 行](ROADMAP.md)、[PRD 第8章笔记组织与教学顺序](../requirements/PRD.md)。
- 任务状态只由[任务账本](../../dev-log/tasks.json)维护，本文件不记状态。
- 切批次只展开执行入口，不自动 start 下一项。
- 边界声明：本批不新增模型提供商、不联网、不做完整阅读器与编辑器；不宣称科学正确率、通用 OCR、
  多教材规模或生产就绪。所有产物停在新测试根内，零模型调用、零网络请求。

## 1 B12-T01 教材式自适应规划：概念关系、教学顺序与规划位置

**单一可见结果**：给定已核对的概念关系、必要原子与主题声明，能确定性产出一份规划，
每个必要原子都有唯一位置，且不会把一条连续反应链拆成一堆单句文件。

**依赖**：B11-T03。

**范围**：只读已冻结的概念关系与已核对 IR，按知识身份而不是文件名组织；
新增能力前缀 `plan`（`plan_model.rs` / `plan_store.rs` / `plan.rs`），只写新测试根。

**顺序**：

1. 冻结一份自造输入：概念关系、必要原子清单、主题声明与阅读目标，并**先手写**规划期望，
   逐个原子写出它的规划位置（文件夹与笔记）。
2. 实现确定性规划：同一冻结输入两次规划字节相同；每个必要原子恰有一个位置，不丢不重。
3. 处理两条硬约束：连续反应链不得无理由拆成单句文件，拆分必须给出可检查的理由
   （链条过长、主题归属或用户锁定），否则整包拒绝；规划不生成知识、不写正文。
4. 更新契约文档、验证记录与日志，整理提交并推送。

**验收**：

- 规划结果与实现前手写的期望逐条一致，原子位置可复算。
- 两次规划字节相同；原子缺位、重复归位或理由缺失都被拒绝并逐条报出。
- 零模型调用、零网络请求，规划根只保存冻结输入与派生报告。
- 独立只读审计器复算规划结果；完整 Rust/Python 回归通过。

**停止**：若必须靠语义相似度猜概念归属才能规划，停止并只记录缺口，不引入启发式修补。

## 2 B12-T02 同一主题的多阅读目标与同类结构一致

**单一可见结果**：同一主题可以按反应、调控、能量等阅读目标分成不同笔记，
而同一概念在整份规划里仍只有一处完整解释位置。

**依赖**：B12-T01。

**范围**：只在已有规划层上加阅读目标拆分与结构一致性校验；新增能力挂在 `plan` 前缀下，
不新增第二套 CLI 动词表。

**顺序**：

1. 冻结同一主题的三个阅读目标与**先手写**的原子归属期望。
2. 实现目标拆分：每个阅读目标一份笔记，原子按目标归属；跨笔记只允许引用或同源嵌入，
   同一概念的完整解释位置仍然唯一。
3. 校验结构一致性：同类同层级的命名、章节顺序与导航深度可复算一致；
   模板是结构规范而非填空，不得为「模板齐全」生成空章节，特殊结构必须记录理由。
4. 报告单列每个阅读目标的原子归属与引用关系；审计器独立复算。

**验收**：

- 三个阅读目标的原子归属与期望一致，唯一解释位置在全份规划里仍只有一个。
- 空章节、无理由的特殊结构与不一致的同类结构都被拒绝并逐条报出。
- 规划报告能定位到具体笔记与章节，不用百分比掩盖偏差。
- 零模型调用、零网络请求；独立审计与完整回归通过。

**停止**：若同一原子必须同时出现在两份完整解释里才能满足阅读目标，停止并记录冲突，
不复制完整解释。

## 3 B12-T03 锁定位置与规划变更的局部影响

**单一可见结果**：用户锁定的结构在增量规划后保持不变，规划变更只影响声明范围内的笔记，
其余笔记逐字节不变。

**依赖**：B12-T02。

**范围**：只在规划层加锁定与增量变更，不写 Vault；新增能力仍挂 `plan` 前缀。

**顺序**：

1. 冻结一份带锁定的规划与**实现前手写**的变更期望：锁定的目录、文件名、章节与顺序，
   以及一次声明范围内的规划变更。
2. 实现锁定保持：与锁定冲突的新规划只进候选并逐条列出冲突，不覆盖已锁定结构。
3. 实现局部影响：未受影响笔记的内容指纹逐字节不变，受影响清单逐条给出原因；
   无法安全同时更新时保留旧位置并给出明确错误。
4. 输出可审查的移动、拆分、合并与引用变化列表，审计器核对列表与实际产物一致。

**验收**：

- 锁定位置在增量规划后完全保持；冲突只进候选且逐条可查。
- 未受影响笔记的指纹逐字节不变，受影响清单与实际改动一一对应。
- 变更清单可直接审查；无法安全更新时以明确错误拒绝，不产生半成品。
- 零模型调用、零网络请求；独立审计与完整回归通过。

**停止**：若必须改动已锁定位置才能完成变更，停止并只报告冲突，不擅自解锁。
