# B11 迁移与追溯执行卡

本批从 B10 已验收的结构规划层继续，补「结构变动之后链接还对不对、来源还能不能找回来」。
三张卡只处理确定性链接解析、可移植索引与全库链接/唯一解释审计，不做模型抽取、不做知识裁决、
不写生产 Vault。

- 进入依据：[路线图 B11 行](ROADMAP.md)、[PRD 第9章笔记结构与知识关联](../requirements/PRD.md)与[第10章来源追溯与结果交付](../requirements/PRD.md)。
- 任务状态只由[任务账本](../../dev-log/tasks.json)维护，本文件不记状态。
- 切批次只展开执行入口，不自动 start 下一项。
- 边界声明：本批不新增模型提供商、不联网、不做完整阅读器与编辑器；不宣称科学正确率、通用 OCR、
  多教材规模或生产就绪。所有产物停在新测试根内，零模型调用、零网络请求。

## 1 B11-T01 小节提升为独立笔记与链接批量更新

**单一可见结果**：给定「小节提升为独立文件」前后的两套作者包，能确定性算出每个受影响引用与
证据映射的迁移结果，并保证知识对象身份不变。

**依赖**：B10-T03。

**范围**：只读已冻结的作者包与已核对 IR，按概念/知识 ID 而不是文件名建立引用；
新增能力前缀 `migrate`（`migrate_model.rs` / `migrate_store.rs` / `migrate.rs`），只写新测试根。

**顺序**：

1. 冻结提升前后的两套自造作者包（原笔记把某小节并入正文；提升后该小节成为独立文件），
   并**先手写**迁移期望表：每个受影响引用的迁移前目标、迁移后目标、证据映射。
2. 实现身份保持与批量更新：概念与原子 ID 不因拆分而变；只重写声明受影响的引用，
   未受影响表示的字节不变。
3. 处理三条硬约束：目标无法安全同时更新时保留旧发布位置并报明确错误（不先移走目标）；
   重复文件名不得误指；表格内别名竖线必须转义。
4. 更新契约文档、验证记录与日志，整理提交并推送。

**验收**：

- 迁移前后每个内部引用都解析到同一知识对象，逐个引用可与期望表对齐。
- 未受影响的表示逐字节不变，只改声明受影响的部分。
- 断链计数为零；无法安全迁移时以明确错误拒绝整包，不产生半迁移产物。
- 独立只读审计器复算迁移结果；完整 Rust/Python 回归通过。

**停止**：若必须猜测链接目标才能迁移，停止并只记录缺口，不引入启发式修补。

## 2 B11-T02 可移植来源索引与原始资料重定位

**单一可见结果**：输出目录可整体复制到新路径后仍能独立阅读，来源索引可单独导出并按内容
摘要把原始资料重新定位。

**依赖**：B11-T01。

**范围**：只做索引导出与重定位，不改笔记正文；新增能力前缀 `index`（`index_model.rs` /
`index_store.rs` / `index.rs`），只写新测试根。

**顺序**：

1. 冻结一个自造工程：输出区、运行库、缓存与临时目录分处不同路径，并**先手写**期望清单。
2. 导出带版本的独立来源索引（JSON），核对运行数据库、缓存与临时文件均未进入输出区。
3. 复制输出到新路径后重新读取：笔记仍可独立阅读，追溯只走索引、正文不插来源编号。
4. 移动原始资料后按内容摘要重定位；资料缺失时明确提示「需重建映射」，不指向错误页面。

**验收**：

- 输出区成员集合固定，运行期文件零泄漏；索引可独立复算。
- 移动资料后重定位成功；资料缺失时给出明确提示，不断言精确匹配。
- 正文保持无来源编号负担，追溯信息只在索引侧。
- 零模型调用、零网络请求；独立只读审计与完整回归通过。

**停止**：若需要访问原始资料之外的网络位置才能重定位，停止并记录未覆盖情形。

## 3 B11-T03 全库链接可用性与唯一解释位置审计

**单一可见结果**：对一份发布集合给出「链接可用率 + 唯一解释位置」两项可复算计数，
并把每个缺口逐条列名而不是只给百分比。

**依赖**：B11-T01、B11-T02。

**范围**：只读发布集合与金标准清单；新增能力前缀 `audit`（`audit_model.rs` / `audit_store.rs` /
`audit.rs`），只写新测试根。

**顺序**：

1. 冻结发布集合的金标准清单与**实现前手写**的期望：关键原子与一般原子分列，
   每个原子给出它在发布集合里的规范位置。
2. 实测链接可用率：内部链接全部解析到预期目标，中文路径、重名标题、表格别名逐条给出解析依据。
3. 实测唯一解释位置：同一概念全库恰有一处完整解释，其余为引用；未召回或不唯一的条目逐条列名。
4. 报告写清口径（分子、分母与「不适用」情形），审计器独立复算并对任何缺口报失败。

**验收**：

- 断链计数为零；链接可用率的分母口径在文档与报告里一致。
- 每个关键原子都能定位到唯一规范位置；缺口逐条列名，不用百分比掩盖。
- 审计器独立复算计数，口径漂移会被发现。
- 零模型调用、零网络请求；完整 Rust/Python 回归通过。

**停止**：若金标准清单本身无法独立复算（例如依赖产品输出），停止并重建清单，
不用产品输出反向定义期望。
