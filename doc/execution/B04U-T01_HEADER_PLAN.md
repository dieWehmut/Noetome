## 范围和设计

顶部采用贯穿窗口的紧凑浅灰应用菜单栏：约 36px 高、18px 线条图标、14px Segoe UI 菜单文字，间距和灰色以用户截图为依据。原面包屑和同栏版本标签移除；侧栏品牌与当前工作台内容沿用。窗口继续使用现有 Windows 原生装饰和关闭行为。

只接已有能力：工作台、运行检查、关于/窗口设置、CLI 帮助/版本。后退和前进维护实际页面访问历史，侧栏可以收起。Edit 提供当前内容全选和有实际选中文本时的复制，错误如实提示；不引入文档编辑器、项目导入、网络或新的桌面权限。

顶栏有可访问名称、展开状态和键盘焦点，菜单支持箭头、Home/End、Enter/Space、Escape 与点击外部关闭。菜单边缘定位考虑 640px 最小窗口及 360px 浏览器预览。帮助/版本继续调用现有 IPC；静态预览的 IPC 失败不能记为桌面成功。
